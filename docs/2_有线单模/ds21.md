# DS21

![IMG_4058_副本.png](https://img.micah.vip/i/2026/06/27/6a3f80cd1aed3.png)

17键+4个旋钮数字小键盘

| 名称     | 参数    | 备注               |     | 名称    | 参数    | 备注     |
| ------ | ----- | ---------------- | --- | ----- | ----- | ------ |
| 按键层数   | 8     |                  |     | PCB尺寸 |       |        |
| 按键数量   | 21    |                  |     | PCB重量 |       |        |
| 灯光     | RGB轴灯 | 下灯位              |     | PCB厚度 | 1.6mm |        |
| 轴体安装方式 | 轴座热插拔 |                  |     | 套件尺寸  |       |        |
| 键盘接口   | Typec |                  |     | 套件重量  |       |        |
| 全键可自定义 | 是     |                  |     | 成品重量  |       | 重量包含键帽 |
| 连接模式   | 有线单模  |                  |     |       |       |        |
| 扫描率    | 1KHz  |                  |     |       |       |        |
| 回报率    | 1KHz  |                  |     |       |       |        |
| 延迟     | 1ms   | 理论延迟，实际可能会在2ms左右 |     |       |       |        |
