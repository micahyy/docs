# 菜籽猫文档

## 什么是菜籽猫？ <br> What is czmao?

菜籽猫（czmao）是一个专注于客制化机械键盘的开源社区，涵盖 PCB 设计、固件开发、驱动工具与键盘说明书。所有 PCB 源文件、固件、JSON 等均开源托管于 GitHub 和 Gitee，免费下载，请勿商用。

czmao is an open-source community focused on custom mechanical keyboards, covering PCB design, firmware, driver tools and keyboard documentation. All PCB source files, firmware, and JSON files are hosted on GitHub and Gitee, free to download, not for commercial use.
