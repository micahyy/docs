# 4.2 DC22 三模（开发中）

22 键三模数字小键盘 · USB / 蓝牙 / 2.4G <br>22-key tri-mode numeric keypad — work in progress

::: warning 本页处于开发中 <br> Work in progress
**有线（USB）通道已在真机验证**：枚举、打字、VIA 改键、落盘全部跑通。

**以下尚未上机验证，参数与按键可能随固件调整**：蓝牙（BLE）、2.4G、低功耗、音乐律动。

Wired (USB) is verified on real hardware. Bluetooth / 2.4G / low power are **not yet verified on hardware**, so specs and keymap may still change.
:::

## 2. 快捷键 <br> Shortcuts

出厂默认值。**全部可在 VIA 里改**（见第 6 节），改完掉电记忆。

### 2.1 基础层 <br> Base layer

## 3. 三模切换 <br> USB / Bluetooth / 2.4G

一句话：**插着线就是 USB；拔了线自己回到上次用的那条蓝牙；手动切走之后不会被拽回去。**

### 3.1 自动切换 <br> Automatic switching

固件按 USB 供电（VBUS）的**跳变沿**自动往返，正常使用不需要手按 `FN + 4`：

| 事件 <br>Event | 固件动作 <br>Behavior |
| ---------------- | -------------------------------- |
| 插上线 <br>Plug in | 立刻切回 **USB**，并记住这个模式 |
| 拔掉线，且当前在 USB <br>Unplug while on USB | 回到**上次用过的那条蓝牙通道**；从没用过蓝牙则回到 1 号通道 |
| 拔掉线，但当前不在 USB <br>Unplug while on 2.4G | 原地不动 |

- **插着线也能切蓝牙**：手动按 `FN + 1/2/3` 之后不会被拽回 USB。
- **插着线上电 = USB 优先**：不会出现「开机停在蓝牙、还得手按 FN + 4」。
- VBUS 有 20ms 去抖，插头抖动不会误触发。

### 3.2 切换时会发生什么 <br> What happens when switching

- **USB 和蓝牙不会同时连着。** 插着线切到蓝牙时，电脑上的 USB 键盘会消失（键盘主动断开总线）；切回 USB 会重新枚举一次。
- 切换前键盘会先放掉所有按着的键，**不会出现「切过去以后有键一直在重复」**。
- **VIA 只在 USB 通道下可用** —— 蓝牙 / 2.4G 下电脑上根本没有这个设备。要改键请先按 `FN + 4` 切回 USB。

### 3.3 指示灯 <br> Status LED

本键盘没有独立状态灯，用**对应按键下面那颗轴下灯**做提示（亮度刻意压暗，只做指示）：

| 动作 <br>Event | 灯位 <br>LED | 样子 <br>Pattern |
| ---------------- | --------------- | -------------------------------- |
| 切到蓝牙 / 还没连上 | 对应通道的数字键下（FN+1 → `1` 键） | **闪蓝，闪到连上为止**（不超时） |
| 蓝牙连上 | 同上 | **常亮 1.5 秒**，然后回归灯效 |
| 蓝牙掉线 | 同上 | 自动回到闪蓝 |
| 切回 USB | `4` 键下 | 常绿 3 秒 |
| 切到 2.4G | `5` 键下 | 常紫 3 秒 |

> 「连上」单独给一次常亮是刻意的：闪停掉和「指示灯放弃了」看起来一样，用户没法从「灯不闪了」判断到底连上没有。

## 4. 蓝牙 <br> Bluetooth

### 4.1 三个配对通道 <br> Three pairing slots

键盘可以记住 **3 台主机**，每台各占一个通道。通道不是「第几台配对过的设备」，而是三个互相独立的槽位：

- 切到某个槽 = 用那个槽的名字广播：`czm_dc22_ble1` / `czm_dc22_ble2` / `czm_dc22_ble3`；
- 绑定信息记在键盘里（掉电不丢），**再连同一台电脑不需要重新配对**，切过去会自动连回；
- 切到哪个通道，键盘就出现在那台电脑的「已连接」里，另外两台那边会显示断开。

> ⚠ **开发中**：切换到某个槽只改广播名，还做不到「按槽位定向连回指定那一台」，最终连上来的是**任意一台已配对的主机**。按槽位定向重连要等「槽位 ↔ 主机地址」对照表做完。

### 4.2 首次配对 <br> Pairing a new host

1. 按住 `FN` 再按 `1` / `2` / `3`，选一个通道 —— 对应数字键下的灯开始闪蓝；
2. 在电脑 / 手机的蓝牙设置里找到 **`czm_dc22_ble1`**（或 `2` / `3`）并连接；
3. 灯变为常亮 1.5 秒后回归灯效，说明已连上，可以打字了。

### 4.3 重新配对 <br> Re-pairing

`FN + 6`：键盘进入「谁都能连」的广播状态 **30 秒**。适合换新电脑、或者绑定信息乱了的时候。30 秒内没有主机连上，广播自动停止（省电，也避免键盘一直挂在别人的蓝牙列表里）。

### 4.4 已知限制 <br> Known limitations

- **媒体键不工作**：音量 / 播放 / 计算器这些在蓝牙下无效，按键不会有反应。原因是协议栈的键盘服务里没有消费者报告，补它要改 HID 报告描述符，排在基本通道上机验证之后。
- **闲置自动断开**：蓝牙闲置 **60 秒**会断开省电，按一下键或碰一下鼠标会重新连上。
- **从未上机验证**：以上行为都是固件代码层的结论，第一次上机时可能还要调整。

## 5. 2.4G <br> 2.4G wireless

**开发中。** `FN + 5` 现在只切通道、亮一次紫灯，不会产生任何输入 —— 射频发送和 USB 接收器都还没做。

## 6. 改键（VIA） <br> Remap with VIA

1. 用 Type-C 线连接电脑，按 `FN + 4` 确认在 **USB 通道**（VIA 只在 USB 下可用）；
2. 打开 [usevia.app](https://usevia.app/)（或 [via.micah.vip](https://via.micah.vip/)）；
3. 导入本键盘的 JSON 后再改键。

改键结果存在键盘里，**换电脑、掉电都不会丢**。`FN + PgUp` 可以把键位恢复出厂。

可选键值里除常规键盘键码外，还有本键盘自己的功能键（VIA 里的名字）：

| VIA 名称 | 作用 |
| ---------------- | ---------------- |
| Mode USB | 切到 USB 有线 |
| Mode BT1 / BT2 / BT3 | 切到蓝牙 1 / 2 / 3 号通道 |
| BT Next | 蓝牙下一个通道 |
| BT Pair | 蓝牙重新配对 |
| Mode 2G4 | 切到 2.4G（开发中） |
| NKRO | NKRO / 6KRO 切换 |
| Battery | 上报电量 |
| LED Tog / LED + / LED - / LED Next | 灯光开关 / 亮度加减 / 下一个灯效 |
| Bootldr | 进入 bootloader |
| Reset | 恢复出厂键位 |

## 7. 灯光 <br> Lighting

- 22 颗轴下灯，49 种灯效，亮度 / 效果 / 速度 / 色相 / 饱和度都掉电记忆；
- 效果切换在 **FN2 层**（长按 `P/`）；
- **音乐律动**（效果列表里叫 Audio Reactive）由电脑推频谱，键盘上没有麦克风，所以需要 PC 端跑一次工具；**仅 USB 通道可用**。
