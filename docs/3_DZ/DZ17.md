# DZ17

17 键双模数字小键盘 · USB 有线 + 蓝牙 5.0 · ZMK 固件
17-key dual-mode numpad · USB wired + Bluetooth 5.0 · ZMK firmware

> DZ17 是 DS17 的无线版本：主控为 nRF52840，支持 USB 有线和蓝牙 5.0 双模，板载 5 颗单色状态指示灯，使用 ZMK 固件，支持 ZMK Studio 实时改键。
> DZ17 is the wireless version of the DS17: powered by an nRF52840, it supports both USB wired and Bluetooth 5.0, features 5 monochrome status LEDs, runs ZMK firmware and supports live keymap editing via ZMK Studio.

## 2. 指示灯说明 <br> LED indicators

### 2.1 通道与状态灯 <br> Channel & status LEDs

| 灯 <br> LED | 颜色 <br> Color | 含义 <br> Meaning |
| :--: | :--: | :-- |
| NumLock | 白 <br> White | 跟随电脑数字锁定状态：NumLock 开启时常亮，关闭时熄灭 <br> Follows the host NumLock state: solid on when NumLock is active, off otherwise |
| BLE 1 | 蓝 <br> Blue | 蓝牙通道 1 指示灯 <br> Bluetooth profile 1 |
| BLE 2 | 蓝 <br> Blue | 蓝牙通道 2 指示灯 <br> Bluetooth profile 2 |
| BLE 3 | 蓝 <br> Blue | 蓝牙通道 3 指示灯 <br> Bluetooth profile 3 |
| USB | 绿 <br> Green | USB 有线通道指示灯 <br> USB wired channel |

**灯效逻辑 <br> LED behavior（通道灯为提示型，确认后熄灭以省电）：**

- 蓝牙模式下，当前通道**未连接/正在广播配对** → 对应蓝灯**闪烁**（约每秒一次），闪烁 **30 秒**后自动熄灭；切换通道、断开重连会重新开始闪烁<br>
  In Bluetooth mode, the blue LED of the current profile **blinks (~1 Hz) while advertising / not connected for ~30 seconds**, then turns off; switching profile or reconnecting restarts the blink.
- 蓝牙**连接成功** → 对应蓝灯**常亮 3 秒**后自动熄灭；使用中断开连接则恢复 30 秒闪烁<br>
  Once connected, the blue LED stays **solid for 3 seconds** as confirmation, then turns off; it resumes the 30-second blink if the connection is lost.
- 切换到 USB 有线通道时，绿灯**常亮 3 秒**后自动熄灭，三个蓝灯保持熄灭（蓝牙与 USB 互斥）<br>
  When the USB channel is selected, the green LED stays **solid for 3 seconds** as confirmation, then turns off; all blue LEDs remain off.
- **插入 USB 线即强制切回 USB 有线模式**（任何状态下）<br>
  **Plugging in the USB cable always forces the keyboard back to USB mode**, regardless of the current state.
- NumLock 白灯不适用此规则，跟随电脑状态常亮/熄灭<br>
  The white NumLock LED is independent and stays solid while NumLock is active.

### 2.2 充电指示灯 <br> Charging LEDs

充电灯由硬件（TP4056）直接控制，与固件无关：
The charging LEDs are driven directly by hardware (TP4056), independent of firmware:

- 🔴 红灯：充电中常亮 <br> Red LED: solid while charging
- 🟢 绿灯：充满电后常亮 <br> Green LED: solid when charging is complete

## 3. 快捷键 <br> Shortcuts

### 3.1 基础层 <br> Base layer

| 按键 <br> Key | 短按 <br> Tap | 长按 <br> Hold |
| :--: | :-- | :-- |
| NUM | 切换 NumLock 数字锁定 <br> Toggle NumLock | 进入 FN 功能层 <br> Hold for FN layer |
| / | 除号 <br> Divide | （预留，进入第二功能层）<br> Reserved (second layer) |

### 3.2 FN 功能层（长按 NUM 不放，再按对应键）<br> FN layer (hold NUM, then tap)

| 快捷键 <br> Combo | 功能 <br> Function |
| :-- | :-- |
| FN + `1` | 切换到蓝牙通道 1 <br> Switch to BLE profile 1 |
| FN + `2` | 切换到蓝牙通道 2 <br> Switch to BLE profile 2 |
| FN + `3` | 切换到蓝牙通道 3 <br> Switch to BLE profile 3 |
| FN + `4` | 切换 USB / 蓝牙输出通道 <br> Toggle USB / Bluetooth output |
| FN + `*` | ZMK Studio 解锁（实时改键）<br> Unlock ZMK Studio (live remap) |
| FN + `-` | 进入 Bootloader（UF2 烧录模式）<br> Enter bootloader (UF2 flashing mode) |
| FN + `.` | 清除蓝牙配对信息 <br> Clear Bluetooth pairings |

> 组合键操作方式：先按住 `NUM` 键不放，再按下对应的数字/符号键，然后松开。
> To use a combo: hold `NUM` down, tap the target key, then release.

## 4. 蓝牙配对与使用 <br> Bluetooth pairing

1. 长按 `NUM` 进入 FN 层，按 `1` / `2` / `3` 选择一个蓝牙通道
   Hold `NUM` and press `1` / `2` / `3` to select a BLE profile.
2. 对应蓝灯开始**闪烁**（约 30 秒后熄灭，重新按通道键可再次广播），在电脑/手机的蓝牙列表中搜索 `czm_dz17_ble_x`（x 为通道号）并连接
   The blue LED **blinks for ~30 seconds** while advertising (press the profile key again to restart it). Find `czm_dz17_ble_x` in your device's Bluetooth list and pair.
3. 连接成功后蓝灯**常亮 3 秒**后熄灭，表示连接成功
   The blue LED stays **solid for 3 seconds**, then turns off.
4. 3 个通道可分别配对 3 台设备，FN + `1/2/3` 一键切换
   Each profile pairs with one device (up to 3). Use FN + `1/2/3` to switch.
5. 切换电脑或连不上时，用 FN + `.` 清除当前通道配对后重新配对
   If pairing fails or you change host, use FN + `.` to clear pairings, then pair again.
6. 插着 USB 线时，可用 FN + `4` 在 USB 有线和蓝牙之间切换
   While a USB cable is connected, FN + `4` toggles between USB and Bluetooth output.

## 5. 改键 <br> Remapping

DZ17 使用 ZMK 固件，推荐通过 **ZMK Studio** 实时改键：
DZ17 runs ZMK. We recommend **ZMK Studio** for live keymap editing:

1. 打开 [菜籽猫驱动中心](https://key.micah.vip)（国内服务器）
   Open the [CZM Driver Center](https://key.micah.vip).
2. 用 USB 线连接键盘（蓝牙模式下不支持 Studio）
   Connect the keyboard via USB (Studio is not available over Bluetooth).
3. 网页识别到键盘后，按 FN + `*` 解锁，即可在网页上实时拖改按键
   Once the keyboard is detected, press FN + `*` to unlock, then drag-and-drop keys live.
4. 拔掉 USB 后自动重新锁定
   The keyboard re-locks automatically when USB is disconnected.

高级用户也可以直接修改开源配置仓库自行编译固件：
Advanced users can edit the open-source config repo and build firmware themselves:
[github.com/micahyy/zmk-config](https://github.com/micahyy/zmk-config)（shield 名：`dz17`）

## 6. 固件烧录 <br> Flashing firmware

1. 长按 `NUM`，按 `-` 进入 Bootloader；或双击主控模块上的复位键
   Hold `NUM` and press `-` to enter the bootloader (or double-tap the RESET button on the module).
2. 电脑上会出现一个名为 `NICENANO` 的 U 盘
   A USB mass-storage drive named `NICENANO` will appear.
3. 将 `.uf2` 固件文件拖入该 U 盘，键盘会自动重启并完成烧录
   Drag the `.uf2` firmware file onto the drive; the keyboard reboots and flashes automatically.

固件下载（GitHub Actions 构建产物）：
Firmware downloads (GitHub Actions build artifacts):
[github.com/micahyy/zmk-config/actions](https://github.com/micahyy/zmk-config/actions)
→ 选择最新一次构建 → Artifacts 中下载 `dz17_firmware` → 解压得到 `dz17_nice_nano_v2.uf2`

## 7. 电源与睡眠 <br> Power & sleep

- 键盘内置可充电锂电池，Type-C 充电，充电状态见 2.2 节
  Built-in rechargeable Li-ion battery, charged via Type-C. See [2.2 Charging LEDs](#_22-充电指示灯-charging-leds).
- 闲置约 5 分钟后自动进入睡眠省电，按任意键唤醒并自动重连
  After ~5 minutes of inactivity the keyboard sleeps to save power; press any key to wake and reconnect.
- 长时间不用建议关闭电源开关（如配备）
  If a power switch is fitted, turn it off for long-term storage.

## 8. 常见问题 <br> FAQ

**Q：蓝灯一直闪、连不上设备？**
**Blue LED keeps blinking and won't connect?**
A：先确认电脑蓝牙已打开；仍不行就 FN + `.` 清除配对，删掉电脑里的旧配对记录后重新配对。
Make sure Bluetooth is enabled on the host. If it still fails, press FN + `.` to clear pairings, remove the old entry from the host, then pair again.

**Q：插着 USB 线但打不了字？**
**Connected via USB but no input?**
A：可能当前输出通道是蓝牙。按 FN + `4` 切换到 USB 通道，绿灯亮 2 秒即 USB 模式。
The output may be set to Bluetooth. Press FN + `4` to switch to USB; the green LED lighting up for 2s means USB mode.

**Q：白灯不亮？**
**White LED doesn't light up?**
A：白灯跟随电脑 NumLock 状态。请确认电脑端数字锁定（NumLock）已开启；部分笔记本默认关闭小键盘 NumLock。
The white LED follows host NumLock. Make sure NumLock is turned on (some laptops disable it by default).

**Q：改键网页识别不到键盘？**
**Remap site can't detect the keyboard?**
A：ZMK Studio 只在 USB 有线连接下工作，请插线后刷新页面，并按 FN + `*` 解锁。
ZMK Studio only works over USB. Plug in the cable, refresh the page, and press FN + `*` to unlock.
