# DZ87

87 键双模机械键盘 · USB 有线 + 蓝牙 5.0 · ZMK 固件
87-key dual-mode mechanical keyboard · USB wired + Bluetooth 5.0 · ZMK firmware

> DZ87 是菜籽猫 87 键（TKL 配列）双模键盘：主控为 nRF52840，支持 USB 有线和蓝牙 5.0，板载 6 颗单色状态指示灯，使用 ZMK 固件，支持 ZMK Studio 实时改键。配列兼容 ANSI/ISO 变体（分裂退格、分裂空格、多种 Shift/回车宽度），可在 ZMK Studio 中查看所有变体位置。
> The DZ87 is an 87-key (TKL layout) dual-mode keyboard from CZMao: powered by an nRF52840, it supports both USB wired and Bluetooth 5.0, features 6 monochrome status LEDs, runs ZMK firmware and supports live keymap editing via ZMK Studio. The physical layout supports ANSI/ISO variants (split backspace, split space, multiple Shift/Enter widths) — all variant positions are visible in ZMK Studio.

## 2. 指示灯说明 <br> LED indicators

### 2.1 通道与状态灯 <br> Channel & status LEDs

| 灯 <br> LED | 颜色 <br> Color | 含义 <br> Meaning |
| :--: | :--: | :-- |
| CapsLock | 白 <br> White | 跟随电脑大写锁定状态：CapsLock 开启时常亮，关闭时熄灭 <br> Follows the host Caps Lock state: solid on when active, off otherwise |
| ScrollLock | 白 <br> White | 跟随电脑滚动锁定状态：ScrollLock 开启时常亮，关闭时熄灭 <br> Follows the host Scroll Lock state: solid on when active, off otherwise |
| BLE 1 | 白 <br> White | 蓝牙通道 1 指示灯 <br> Bluetooth profile 1 |
| BLE 2 | 白 <br> White | 蓝牙通道 2 指示灯 <br> Bluetooth profile 2 |
| BLE 3 | 白 <br> White | 蓝牙通道 3 指示灯 <br> Bluetooth profile 3 |
| USB | 白 <br> White | USB 有线通道指示灯 <br> USB wired channel |

> 6 颗指示灯均为白色 LED，通道身份由位置区分。<br>
> All six indicator LEDs are white; the channel is told apart by position.

**灯效逻辑 <br> LED behavior（通道灯为提示型，确认后熄灭以省电）：**

- 蓝牙模式下，当前通道**未连接/正在广播配对** → 对应通道灯**闪烁**（约每秒一次），闪烁 **30 秒**后自动熄灭；切换通道、断开重连会重新开始闪烁<br>
  In Bluetooth mode, the channel LED **blinks (~1 Hz) while advertising / not connected for ~30 seconds**, then turns off; switching profile or reconnecting restarts the blink.
- 蓝牙**连接成功** → 对应通道灯**常亮 3 秒**后自动熄灭；使用中断开连接则恢复 30 秒闪烁<br>
  Once connected, the channel LED stays **solid for 3 seconds** as confirmation, then turns off; it resumes the 30-second blink if the connection is lost.
- 切换到 USB 有线通道时，USB 灯**常亮 3 秒**后自动熄灭，三个通道灯保持熄灭（蓝牙与 USB 互斥）<br>
  When the USB channel is selected, the USB LED stays **solid for 3 seconds** as confirmation, then turns off; all BLE channel LEDs remain off.
- **插入 USB 线即强制切回 USB 有线模式**（任何状态下）<br>
  **Plugging in the USB cable always forces the keyboard back to USB mode**, regardless of the current state.
- CapsLock / ScrollLock 灯不适用此规则，跟随电脑状态常亮/熄灭<br>
  The CapsLock and ScrollLock LEDs are independent and follow the host state.

## 3. 快捷键 <br> Shortcuts

键盘有两个功能层：

- **FN 层**：长按主键区右下角的 **FN** 键（右 Ctrl 左侧）进入，用于蓝牙通道、多媒体等常用功能
  Hold the **FN** key (bottom row, left of Right Ctrl) to access the FN layer.
- **FN2 层**：按住 **FN** 再按 **右Alt** 组合进入（标准 87 键配列无独立 FN2 键）。用于 Studio 解锁、清配对、Bootloader 等维护功能
  The maintenance layer is accessed by holding **FN** and then pressing **Right Alt** (there is no separate FN2 key on the standard layout).

### 3.1 FN 层（按住 FN，再按对应键）<br> FN layer (hold FN, then tap)

| 快捷键 <br> Combo | 功能 <br> Function |
| :-- | :-- |
| FN + `1` | 切换到蓝牙通道 1（长按 1 秒进入该通道配对模式）<br> Switch to BLE profile 1 (hold 1s to enter pairing mode) |
| FN + `2` | 切换到蓝牙通道 2（长按 1 秒进入配对模式）<br> Switch to BLE profile 2 (hold 1s to pair) |
| FN + `3` | 切换到蓝牙通道 3（长按 1 秒进入配对模式）<br> Switch to BLE profile 3 (hold 1s to pair) |
| FN + `4` | 手动切换到 USB 有线输出（插入 USB 线时通常自动切换）<br> Manually select USB wired output (usually automatic when the cable is plugged in) |
| FN + `P` | 打开系统默认媒体播放器 <br> Launch the system media player |
| FN + `C` | 打开系统计算器 <br> Launch the system calculator |
| FN + `空格` | 播放 / 暂停 <br> Play / pause |
| FN + `↑` | 音量加 <br> Volume up |
| FN + `↓` | 音量减 <br> Volume down |
| FN + `←` | 上一曲 <br> Previous track |
| FN + `→` | 下一曲 <br> Next track |
| FN + `右Alt` | 进入 FN2 维护层（再按维护键）<br> Enter the FN2 maintenance layer |

> 组合键操作方式：先按住 **FN** 不放，再按下对应键，然后松开。<br>
> To use a combo: hold **FN** down, tap the target key, then release.

### 3.2 FN2 维护层（按住 FN 不放，按 右Alt 保持进入 FN2 层，再按对应键）<br> FN2 layer (hold FN, tap Right Alt, then tap)

| 快捷键 <br> Combo | 功能 <br> Function |
| :-- | :-- |
| FN + 右Alt + `` ` ``（ESC 右侧的 `~ 键） | ZMK Studio 解锁（实时改键）<br> Unlock ZMK Studio (live remap) |
| FN + 右Alt + `ESC` | 清除蓝牙配对信息 <br> Clear all Bluetooth pairings |
| FN + 右Alt + `左Ctrl` | 进入 Bootloader（UF2 烧录模式）<br> Enter bootloader (UF2 flashing mode) |

## 4. 蓝牙配对与使用 <br> Bluetooth pairing

1. 按住 FN，按 `1` / `2` / `3` 选择一个蓝牙通道
   Hold FN and press `1` / `2` / `3` to select a BLE profile.
2. 对应通道灯开始**闪烁**（约 30 秒后熄灭；长按 FN+对应数字键 1 秒可重新进入配对广播），在电脑/手机的蓝牙列表中搜索 `czm_dz_87_ble_x`（x 为通道号）并连接
   The channel LED **blinks for ~30 seconds** while advertising (hold FN + the number for 1s to restart it). Find `czm_dz_87_ble_x` in your device's Bluetooth list and pair.
3. 连接成功后通道灯**常亮 3 秒**后熄灭，表示连接成功
   The channel LED stays **solid for 3 seconds**, then turns off.
4. 3 个通道可分别配对 3 台设备，FN + `1/2/3` 一键切换
   Each profile pairs with one device (up to 3). Use FN + `1/2/3` to switch.
5. 切换电脑或连不上时，用 FN + 右Alt + `ESC` 清除配对后重新配对
   If pairing fails or you change host, use FN + Right Alt + `ESC` to clear pairings, then pair again.
6. 插着 USB 线时键盘强制走 USB 有线；拔线或用 FN + `4` 可切回蓝牙
   With the USB cable plugged in the keyboard forces USB mode; unplug or press FN + `4` to return to Bluetooth.

## 5. 改键 <br> Remapping

DZ87 使用 ZMK 固件，推荐通过 **ZMK Studio** 实时改键：
DZ87 runs ZMK. We recommend **ZMK Studio** for live keymap editing:

1. 打开 [菜籽猫驱动中心](https://zmk.micah.vip)（官方版：[zmk.studio](https://zmk.studio)）
   Open the [CZM Driver Center](https://zmk.micah.vip) (official build: [zmk.studio](https://zmk.studio)).
2. 用 USB 线连接键盘（蓝牙模式下不支持 Studio）
   Connect the keyboard via USB (Studio is not available over Bluetooth).
3. 网页识别到键盘后，按住 FN 按 右Alt 进入维护层，再按 `` ` `` 键解锁，即可在网页上实时拖改按键
   Once the keyboard is detected, hold FN, tap Right Alt to enter the maintenance layer, then press `` ` `` to unlock; drag-and-drop keys live.
4. Studio 中有三种配列视图可选（键盘右上角配列切换菜单）：
   Three layout views are available in Studio (layout switch menu in the top-right corner):

   - **ANSI 6.25u 空格（默认）**：标准美式 87 键配列，出厂即此视图
     Standard ANSI 87-key layout (factory default).
   - **ANSI 7u 空格**：空格 7u、无右 Win 键的配列
     ANSI layout with a 7u spacebar (no Right Win key).
   - **全轴通用 ALL**：显示 PCB 上全部 94 个轴位，包含 ISO 回车/NUBS、分裂退格、分裂空格等所有变体位置。焊接了非标准轴位（如 ISO 大回车、分裂空格）时切到这个视图即可对所有轴改键
     Shows all 94 switch positions on the PCB — ISO enter / NUBS, split backspace, split space and all other variants. Switch to this view if your board has non-standard switches soldered in.

   切换视图不会丢失已改的键：同一功能的位置（如分裂空格各轴、分裂退格）会自动迁移，实际不存在的轴位保持原样不受影响。
   Switching views never loses your keymap: functionally equivalent positions (split space switches, split backspace) are migrated automatically; positions that don't exist on your board are simply left untouched.
5. 拔掉 USB 后自动重新锁定
   The keyboard re-locks automatically when USB is disconnected.

高级用户也可以直接修改开源配置仓库自行编译固件：
Advanced users can edit the open-source config repo and build firmware themselves:
[github.com/micahyy/zmk-config](https://github.com/micahyy/zmk-config)（shield 名：`dz_87`）

## 6. 固件烧录 <br> Flashing firmware

1. 按住 FN 按 右Alt 进入维护层，再按 `左Ctrl` 进入 Bootloader；或双击主控模块上的复位键
   Hold FN, tap Right Alt to enter the maintenance layer, then press `Left Ctrl` to enter the bootloader (or double-tap the RESET button on the module).
2. 电脑上会出现一个名为 `NICENANO` 的 U 盘
   A USB mass-storage drive named `NICENANO` will appear.
3. 将 `.uf2` 固件文件拖入该 U 盘，键盘会自动重启并完成烧录
   Drag the `.uf2` firmware file onto the drive; the keyboard reboots and flashes automatically.

固件文件见**文末「固件下载」**区块 / Get the firmware from the **Firmware download** section at the bottom of this page.

## 7. 电源与睡眠 <br> Power & sleep

- 键盘内置可充电锂电池，Type-C 充电
  Built-in rechargeable Li-ion battery, charged via Type-C.
- 闲置约 5 分钟进入浅睡眠省电（蓝牙保持连接，任意键即时唤醒）；约 15 分钟进入深度睡眠（断开蓝牙，指示灯全灭），按任意键唤醒并自动重连
  After ~5 minutes of inactivity the keyboard enters light sleep (Bluetooth stays connected, wakes instantly); after ~15 minutes it enters deep sleep (Bluetooth off, all LEDs off) — press any key to wake and reconnect.
- 长时间不用建议关闭电源开关（如配备）
  If a power switch is fitted, turn it off for long-term storage.

## 8. 常见问题 <br> FAQ

**Q：通道灯一直闪、连不上设备？**
**The channel LED keeps blinking and won't connect?**
A：先确认电脑蓝牙已打开；仍不行就 FN + 右Alt + `ESC` 清除配对，删掉电脑里的旧配对记录后重新配对。
Make sure Bluetooth is enabled on the host. If it still fails, press FN + Right Alt + `ESC` to clear pairings, remove the old entry from the host, then pair again.

**Q：插着 USB 线但打不了字？**
**Connected via USB but no input?**
A：正常情况下插线即走 USB 有线通道（USB 灯亮 3 秒提示）。如异常可按 FN + `4` 手动切换输出通道。
Plugging in the cable normally selects USB (the USB LED lights for 3s). If something seems off, press FN + `4` to toggle the output manually.

**Q：CapsLock / ScrollLock 灯不亮？**
**The CapsLock / ScrollLock LED doesn't light up?**
A：这两颗灯跟随电脑对应的锁定状态，请确认电脑端 Caps Lock / Scroll Lock 已开启。
These LEDs follow the host's lock states — make sure Caps Lock / Scroll Lock is turned on.

**Q：改键网页识别不到键盘 / 提示未解锁？**
**Remap site can't detect or unlock the keyboard?**
A：ZMK Studio 只在 USB 有线连接下工作，请插线后刷新页面，按住 FN 按 右Alt 进入维护层后按 `` ` `` 解锁。
ZMK Studio only works over USB. Plug in the cable, refresh the page, then hold FN, tap Right Alt and press `` ` `` to unlock.

**Q：Studio 配列图里看不到我键盘上的轴（ISO 回车 / 分裂空格等）？**
**My switches (ISO enter / split space) don't appear in the Studio layout?**
A：请把配列视图切换为「全轴通用 ALL」（Studio 右上角配列切换菜单），该视图显示 PCB 上全部 94 个轴位；标准 ANSI 键盘保持默认「ANSI 6.25u」视图即可。
Switch the layout view to **全轴通用 ALL** (layout menu in Studio's top-right corner) — it shows all 94 switch positions. Standard ANSI boards can stay on the default **ANSI 6.25u** view.
