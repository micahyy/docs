## 2. 触底校准（自适应触发）<br> Actuation calibration

EC87 的静电容触发点会随胶碗、弹簧、温湿度和使用习惯产生轻微漂移。固件内置**自动学习**，无需任何手动操作：

- **正常打字就是在校准。** 每颗键在你按到底的过程中自动学习触底行程，按得越多次越贴合你的手感；
- 停止打字 5 秒后，学到的数据自动写入键盘内部 Flash；
- 数据**掉电不丢、刷新固件也不丢**（校准数据独立存放在芯片 Flash 的专用页，固件升级不会覆盖）；
- 未学习过的键使用出厂默认阈值，到手即可正常使用。

### 网页可视化校准（可选）<br> Web calibration (optional)

想一次性快速校准全部按键，或想看看每颗键的实时按压行程：

1. 用 **Chrome / Edge** 浏览器打开 [CZM 驱动中心 - EC87 触底校准](https://key.micah.vip/ec87-calib.html)
2. 插上键盘，点击「**连接 EC87**」，在弹窗中选择键盘后点连接
3. 点击「**开始校准**」，然后**把每个键按到底再松开**（正常力度按到底即可）
4. 页面上对应键位会显示金色按压深度，学完后变绿打勾；87 个键全部变绿后点「**保存到键盘**」
5. 「**清除校准数据**」可清空已学数据，恢复出厂阈值

> 网页校准和自动学习共用同一套数据，两种方式混用没有冲突。重按任意键即可覆盖该键的旧数据。

## 3. 驱动与改键 <br> Driver & keymap

- **在线改键**：打开 [usevia.app](https://usevia.app)，点击 **Authorize device** 选择 EC87，即可可视化改键、改层、设置组合键，改完即时生效，无需刷机；
- VIA 键位定义由驱动中心自动加载，无需手动导入 JSON；
- 键盘默认 2 层：第 0 层为正常键位，**按住 Fn（Mo(1)）** 进入第 1 层功能层。

### Fn 功能层 <br> Fn layer

键盘右下角 **Fn**（右 Shift 右侧）和主键区 **Fn**（空格右侧）等效，均为 Mo(1) 功能层。

| 快捷键 <br>Shortcut | 功能 <br>Function |
| :-- | :-- |
| Fn + F1 | 底灯开关 <br>Underglow on/off |
| Fn + F2 / F3 | 底灯亮度 - / + <br>Brightness - / + |
| Fn + F5 / F6 | 切换灯效（下一个 / 上一个）<br>Cycle effect next / prev |
| Fn + F7 / F8 / F9 | 上一曲 / 播放暂停 / 下一曲 <br>Prev / Play / Next |
| Fn + F10 / F11 / F12 | 静音 / 音量 - / 音量 + <br>Mute / Vol- / Vol+ |
| Fn + Scroll Lock（ScrLk） | 进入刷机模式（见下节）<br>Enter bootloader |
| Fn + 方向键 | Home / PgUp / PgDn / End |

> RGB 灯珠位于键盘**背面底部**，主要用于桌面氛围光（underglow），不用于状态指示。

## 4. 固件升级 <br> Firmware update

EC87 使用 uf2boot 引导，刷固件像拷文件一样简单：

1. 从菜籽猫提供的链接下载最新固件 `.uf2` 文件（**via 版**带完整改键功能，普通用户刷 via 版即可）；
2. **按住键盘左上角 ESC 键的同时插入 USB 线**（或在 VIA 中执行 Bootloader 指令），键盘会进入刷机模式，电脑上出现一个名为 **`UF2BOOT`** 的 U 盘；
3. 把 `.uf2` 文件**拖进这个 U 盘**，键盘会自动写入并重启，升级完成；
4. 刷错固件或键盘无反应时，重复第 2 步重新拖入正确固件即可，不会变砖。

> 固件升级不会清除触底校准数据。

## 5. 常见问题 <br> FAQ

**Q：需要手动校准吗？**
不需要。正常打字就会自动学习。网页校准只是给想"一次到位"或想看可视化数据的用户准备的。

**Q：VIA 网页识别不到键盘？**
① 确认用的是数据线不是纯充电线；② 换一个 USB 口重插；③ 浏览器必须是 Chrome 或 Edge（Safari / Firefox 不支持 WebHID）。

**Q：触发感觉变了 / 某颗键要按很重才触发？**
打开校准网页点「清除校准数据」，然后正常打字或重新走一遍网页校准即可；若仍异常，检查该键胶碗是否安装到位。

**Q：刷固件会丢校准数据吗？**
不会。校准数据存放在独立的 Flash 页，刷新固件不覆盖。

**Q：背面的灯能关掉吗？**
可以，**Fn + F1** 关闭底灯（见功能层说明）。
