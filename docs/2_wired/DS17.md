## 9. 常见问题 <br> FAQ

### 9.1 键盘突然不能用了 <br> Board suddenly stops working

键盘键值设置为小键盘区域。使用时，需要电脑开启 Number Lock，才能正常输入数字键。 <br>The keypad layer is assigned to the numpad region. Make sure Number Lock is ON on your host to get number input.

当 Number Lock 关闭时，小键盘上的 8、4、2、6 键会分别变为上、左、下、右方向键。 <br>When Number Lock is OFF, keys 8 / 4 / 2 / 6 act as the arrow cluster (Up / Left / Down / Right).

需要注意的是，Number Lock 读取的是电脑当前的状态，因此您也可以使用其他键盘来开启或关闭 Number Lock。 <br>Note: the board reads the current host Num‑Lock state, so you can turn it on/off from any other keyboard connected to the same computer.
