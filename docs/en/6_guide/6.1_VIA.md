## 1. What is VIA?

VIA is software for remapping keys in real time. Its main advantage: after changing a key mapping you don't need to recompile or flash the firmware — the change takes effect immediately.

Instant effect: once you remap a key in the UI, the keyboard updates immediately; no flashing needed.

Intuitive: a graphical interface where you assign functions by dragging and dropping.

Full-featured: supports multiple layers, macros, RGB lighting effects and other advanced functions.

### Relationship between VIA and QMK

VIA can be seen as a graphical management tool for QMK firmware.

QMK is the underlying engine: it implements all the features in code, but changing the configuration usually means editing code, compiling and flashing — a high barrier.

VIA is the control layer: it wraps QMK's complexity in a visual interface so you can adjust the keyboard easily. All changes are still executed by the QMK firmware.

### How to use VIA

The workflow looks like this:

Check firmware support: the keyboard firmware must include VIA support.

Connect the keyboard: plug it into the computer with a cable.

Open the configuration site: open your browser and go to via.micah.vip to start configuring.

Compatibility notes for different keyboards:

Keyboards from us: this site detects them directly, no extra configuration needed.

Keyboards from other sources: if the keyboard isn't detected automatically, download the matching JSON file from the manufacturer's website, then import it manually on VIA's "Design" tab.

## 2. Importing a JSON file in VIA

> If you use a keyboard sold by CZMao you can skip this step — it is detected automatically.

1. Open via.micah.vip

2. Click Settings (the gear icon) and enable "Show Design Tab".

![10015.png](https://img.micah.vip/i/2026/04/23/69e9a4bcb5cc8.png)

3. Click the brush icon (Design) to switch to the Design tab, then click Load and pick the JSON file for your keyboard.

![](https://img.micah.vip/i/2026/04/23/imgae6.png)

4. Go back to the Configure tab, click "Authorize Device" and select your keyboard.

![10014.png](https://img.micah.vip/i/2026/04/23/69e9a4bd4ec33.png)

5. After confirming, the keyboard layout appears and you can remap as you like.

### Using the Any key

#### The Any key in QMK

In the QMK context, the "Any key" (`KC_ANY` or `ANY()`) is not a standard keycode with a fixed function. What it means depends on which QMK flavour you use (mainly VIA or VIAL).

##### In short

- **In VIA**: `ANY` is a placeholder / spare "custom key". When you can't find the function you want in the graphical UI, pick `ANY` and **type in a keycode or macro name QMK understands**. Think of it as a code injector that lets you use any function VIA's menus don't expose.

- **In VIAL**: `ANY` is a core part of **Tap Dance**. VIAL lets one key output completely different things on tap, double-tap, hold, and so on. Here `ANY` can type complex strings, key combos, or even control the mouse — in short, one key doing many jobs.

##### VIA vs VIAL

| Feature | **VIA** | **VIAL** |
|:-------- |:------------------------------- |:----------------------------------------------- |
| **Purpose** | A "code entry point" for **unusual / rarely used functions** | The core tool behind **Tap Dance** — one key, many meanings (tap = A, double-tap = B) |
| **Main use** | Enter special functions that aren't in the QMK standard but are implemented in the firmware | Assign different actions to tap, double-tap, hold on the same key |
| **Example** | Type `MACRO_F6` from your firmware into the `ANY` box | In VIAL's Tap Dance options, pick `ANY` actions for each trigger |

##### Summary

When someone says "use the Any key for this", they usually mean **using the `ANY` option in the VIA/VIAL interface to type in a custom function name or keycode, achieving behaviour the normal menus don't offer.**

#### How to use it

Pick a key and change it to ANY.

![10008.png](https://img.micah.vip/i/2026/04/23/69e9a4bc012bd.png)

Enter the keycode below and confirm.

    QK_CLEAR_EEPROM

![10009.png](https://img.micah.vip/i/2026/04/23/69e9a4bb5fe2b.png)

Pressing the remapped key now resets the keyboard to factory defaults.
