# 1.1 Cherry G80-3000 conversion PCB

## Unifying (Logitech) conversion PCB

My take on a Unifying conversion:

1. The point of a Unifying conversion is stability and low power consumption.

2. Keep the board as original as possible.

3. Keep the cost as low as reasonably possible.

So the conversion PCB was designed around the following:

    Hot-swap + soldered options: hot-swap needs a plate, but the original case is plateless and would require adding one. So both options are kept — solder it once and you're done, or go hot-swap and be able to re-do it as often as you like.

    Backlight: the design is based on the K375S, which has no lighting support. Adding lighting would need an extra controller, costing power and stability, so no lighting was added.

The final solution only supports the native K375S, keeping battery life and performance intact.

## Wired single-mode conversion PCB

The wired single-mode PCB will be produced later. It keeps only the soldered option and can be installed in the original plateless case without modification.

    Supports multiple layouts.

    Per-switch RGB in the bottom position.

    Detachable cable design, with the original cable connector footprint kept (the connector has to be bought and soldered by yourself).
