# Download Center

Firmware, VIA keymap definitions, drawings and documents — **63** files, **8.3 MB** in total.

## Before you download

1. **Firmware** (`.uf2`): hold the top-left `Esc` key while plugging in the USB cable to enter flashing mode; a USB drive named `UF2BOOT` appears on the computer — drag the file onto it.
2. **Keymap definitions** (`.json`): only needed when the model isn't found in [CZMao VIA](https://via.micah.vip).
3. **Flashing firmware does not clear calibration data** — electrostatic-capacitive keyboards don't need re-calibration after flashing.
4. **Drawings** (`.dxf`) are meant to be used with the matching structural parts; confirm the version before ordering any machining.
5. File names carry the model (e.g. `a14_ds17_R2_via.json` belongs to the DS17); if you can't find yours, double-check the keyboard version first.
6. If a file is missing or a link is dead, please report it in QQ group **677654482**.
