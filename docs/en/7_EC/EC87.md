## 2. Actuation calibration (self-learning trigger)

The electrostatic trigger point may drift slightly with the rubber dome, spring, temperature, humidity and your typing habits. The firmware has **automatic learning** built in — no manual work required:

- **Just type normally and you're calibrating.** Each key learns its bottom-out travel as you press it; the more you press, the closer it matches your feel.
- After 5 seconds of no typing, the learned data is written to the keyboard's internal Flash automatically.
- The data **survives power loss and firmware updates** — calibration data lives in a dedicated Flash page, firmware upgrades don't touch it.
- Unlearned keys use the factory default threshold — the keyboard works out of the box.

### Web calibration (optional)

To calibrate all keys at once, or to visualize each key's learning state:

1. Open the [**CZM Keyboard Calibration**](https://key.micah.vip/calibration.html) page in **Chrome / Edge** (a universal calibration page shared by all our electrostatic-capacitive PCBs);
2. Plug in the keyboard; the **PCB model list** on the left will auto-detect and lock to the current keyboard. If you have multiple keyboards, confirm that EC87 is highlighted;
3. Tick the **layout options** at the top to match your installed keycaps (spacebar length, split space / enter, etc.); only the selected layout shows on the diagram;
4. Click **Start Calibration**; the keyboard enters **silent mode** (no key events are sent to the host during this time — normal), then **press each key all the way down and release** (normal pressure is enough);
5. Pressed keys glow **gold** (idle jitter is filtered, no flickering when your hands are off the keyboard), turning **green with a ✓** when learned; once all keys are green, click **Save Calibration**;
6. To exit mid-calibration and resume typing, click **Resume Key Output**; click **Clear and Retry** to wipe learned data and restore factory thresholds; silent mode auto-resumes output after 10 minutes of inactivity.

> Place the keyboard on a flat stable surface and don't rest on any keys during calibration. The web calibration and auto-learning share the same data — mixing them is fine; new keys revealed by switching layout options just need a fresh press.

## 3. Driver & keymap

- **Live remap**: open CZMao VIA at **[via.micah.vip](https://via.micah.vip)**, click **Authorize device**, select EC87, and you can visually remap, add layers, and set combos — changes take effect instantly without reflashing;
- CZMao VIA already includes keymap definitions for all our keyboards, recognized automatically — **no manual JSON import needed** (the official usevia.app doesn't include our keyboards; not recommended);
- The keyboard has two function layers: **Fn** (bottom row, left of Right Ctrl) = Mo(1) media & system layer; the RGB layer (Mo(2)) is entered by the **Fn + Right Alt** combo (Right Alt sits to the right of the spacebar; split-Shift versions have a separate Fn2 key between Right Shift and ↑ — same effect).

### Fn layer (media / system)

Hold the bottom-row **Fn** key (left of Right Ctrl):

| Shortcut | Function | Note |
| :-- | :-- | :-- |
| Fn + P | Open media player |  |
| Fn + Space | Play / Pause |  |
| Fn + Left / Right | Previous / Next track |  |
| Fn + Up / Down | Volume + / Volume - |  |
| Fn + Backspace | Delete |  |
| Fn + Esc | ` (backtick) |  |
| Fn + Right Alt | Enter Fn2 RGB layer | Hold, then tap RGB keys |

### Fn2 layer (RGB)

**To enter**: hold the bottom-row Fn and press Right Alt (to the right of the spacebar) — the "Fn + Right Alt" combo. On split-Shift versions you can also press the dedicated Fn2 key to the right of Right Shift. Hold the combo and tap the keys below:

| Shortcut | Function |
| :-- | :-- |
| Fn2 + Esc | Factory reset |
| Fn2 + Left Shift | Underglow on/off |
| Fn2 + Z / X | Brightness - / + |
| Fn2 + C / V | Hue - / + |
| Fn2 + B / N | Saturation - / + |
| Fn2 + M / , (comma) | Speed - / + |
| Fn2 + . (period) / / (slash) | Cycle effect next / prev |

> RGB LEDs are on the **rear** of the keyboard. They're intended for desk underglow ambience, not status indication.

### Entering the bootloader

Any of the following works (see "Firmware update" below for details):

1. **Hold the top-left Esc key while plugging in USB**;
2. Issue the Bootloader command in VIA;
3. **Press Left Ctrl + Right Alt + Fn simultaneously** (Fn is the bottom-row function key).

## 4. Firmware update

EC87 uses uf2boot for the bootloader — flashing is as simple as copying a file:

1. Download the latest `.uf2` firmware file from the CZMao link (**via version** has full remap capability; ordinary users should flash the via version);
2. **Hold the top-left ESC key while plugging in USB** (or issue the Bootloader command in VIA); the keyboard enters flashing mode and a USB drive named **`UF2BOOT`** appears on your computer;
3. **Drag the `.uf2` file onto the drive**; the keyboard writes and reboots automatically — upgrade complete;
4. If you flash the wrong firmware or the keyboard becomes unresponsive, repeat step 2 and drag in the correct firmware — it won't brick.

> Firmware updates don't clear the actuation calibration data.

## 5. FAQ

**Q: Do I need to calibrate manually?**
No. Just typing normally triggers auto-learning. Web calibration is only for users who want a "one-shot" calibration or want to see visualized data.

**Q: The VIA web page doesn't recognize the keyboard?**
① Make sure you're using a data cable, not a charge-only cable. ② Try a different USB port and replug. ③ The browser must be Chrome or Edge (Safari / Firefox don't support WebHID).

**Q: Trigger feel changed / a key needs much more force to register?**
Open the calibration page and click **Clear and Retry**, then either resume normal typing or redo the web calibration. If it still feels abnormal, check that the rubber dome is properly seated.

**Q: Does flashing firmware erase calibration data?**
No. Calibration data is stored in a dedicated Flash page, separate from firmware.

**Q: Can I turn off the rear underglow?**
Yes — press **Fn2 + Left Shift** to disable it (see Fn2 layer notes above).
