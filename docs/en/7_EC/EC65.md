## 2. Bottom-out Calibration (adaptive actuation)

The EC65 capacitive trigger point drifts slightly with the rubber dome, spring, temperature, humidity and usage habits. The firmware has built-in **auto-learning** — no manual action needed:

- **Normal typing is calibration.** Each key auto-learns its bottom-out travel as you press it to the bottom; the more you type, the better it fits your feel.
- 5 seconds after you stop typing, the learned data is written to the keyboard's internal Flash automatically.
- Data is **kept on power loss and survives firmware updates** (calibration lives in a dedicated Flash page, not overwritten by firmware upgrades).
- Unlearned keys use the factory default threshold and work out of the box.

### Web visual calibration (optional)

To calibrate all keys at once, or to visualize each key's learned state:

1. Open [**CZM bottom-out calibration**](https://tools.micah.vip/ectools) in **Chrome / Edge** (a shared page for all our capacitive PCBs; or use the **EC tools** entry in the micah.vip top nav);
2. Plug in the keyboard, click **Connect keyboard**, and **select your keyboard** from the device list (all local HID devices are listed, any model); once connected, make sure **EC65** is highlighted on the left PCB list, otherwise click it;
3. Tick the **layout options** at the top (spacebar length, split space / enter, etc.) to match your keycaps — only the selected layout is shown;
4. Click **Start calibration**; the keyboard enters **silent mode** (no output to the PC during this, which is normal), then **press every key on the map to the bottom and release** (normal force is fine);
5. A key shows **gold highlight** while pressed (idle jitter filtered, no flicker when you don't touch it), turns **green with a check ✓** once learned; when all keys are green, click **Save calibration**;
6. Click **Resume output** to exit typing midway; click **Clear & restart** to wipe learned data and restore factory thresholds; 10 minutes idle in silent mode also resumes output automatically.

> Place the keyboard steady and don't hold any key down before calibrating. Web calibration and auto-learning share the same data and don't conflict; after changing layout options, just press the newly shown keys once.

## 3. Drivers & Remapping

- **Online remap**: open CZMAO VIA at **[via.micah.vip](https://via.micah.vip)**, click **Authorize device** and select EC65 to remap keys/layers/combos visually — changes apply instantly, no flashing needed;
- CZMAO VIA already has every keyboard's keymap built in, so it's recognized on connect — **no manual JSON import** (the official usevia.app does not list our models, don't use it);
- The keyboard has two function layers: **Fn** (bottom row, right of Right-Alt, left of the ← arrow) = Mo(1) media/system layer; **Fn2** is entered via **Fn + Left Alt** (system / NKRO / bootloader layer).

### Fn layer (media / system)

Hold the bottom-row **Fn** (right of Right-Alt):

| Shortcut | Function | Note |
| :-- | :-- | :-- |
| Fn + P | Open default media player |  |
| Fn + Space | Play / Pause |  |
| Fn + ← / → | Previous / Next track |  |
| Fn + ↑ / ↓ | Volume + / - |  |
| Fn + Backspace | Mute |  |
| Fn + Esc | ` (backtick) |  |
| Fn + 1 … = | F1 … F12 | maps to 1 2 3 4 5 6 7 8 9 0 - = |
| Fn + Left Alt | Enter Fn2 layer (Mo(2)) | hold, then press Fn2 keys |

### Fn2 layer (Fn + Left Alt)

**Enter by holding Fn, then pressing Left Alt.** While held, press the keys below:

| Shortcut | Function |
| :-- | :-- |
| Fn2 + Left Ctrl | Enter bootloader (flashing mode) |
| Fn2 + Esc | Factory reset (restore default keymap + wipe all learned bottom-out levels + auto reboot) |
| Fn2 + Left Win | NKRO (full N-key rollover) toggle |

> Fn2 + Esc is the same action as VIA's **Functions › General › Factory Reset** button: keymap returns to firmware defaults, all learned bottom-out levels are wiped, and the keyboard reboots once.

### Enter bootloader

Either method works (see "Firmware upgrade" below):

1. Run the Bootloader command in VIA;
2. **Fn + Left Alt + Left Ctrl** together (Fn is the bottom-row function key).

## 4. Firmware upgrade

EC65 uses the uf2boot bootloader — flashing is as simple as copying a file:

1. Download the latest firmware `.uf2` from the link CZMAO provides (**via** build has full remap support; normal users flash the via build);
2. Run the Bootloader command in VIA (or press **Fn + Left Alt + Left Ctrl**); the keyboard enters flashing mode and a **`UF2BOOT`** drive appears on your PC;
3. **Drag the `.uf2` file into that drive** — the keyboard writes it and reboots automatically;
4. If you flash the wrong firmware or the keyboard is unresponsive, just repeat step 2 and drag the correct firmware in again — it can't be bricked.

> Firmware upgrade does not clear calibration data.

## 5. FAQ

**Q: Do I need to calibrate manually?**
No. Normal typing auto-learns. Web calibration is just for users who want "all at once" or to see the visualization.

**Q: VIA can't see the keyboard?**
① Use a data cable, not a charge-only cable; ② try another USB port; ③ the browser must be Chrome or Edge (Safari / Firefox don't support WebHID).

**Q: Actuation feels off / a key needs a hard press?**
Open the calibration page and click **Clear & restart**, then type normally or re-run web calibration; if it persists, check the key's rubber dome is seated.

**Q: Does flashing wipe calibration?**
No. Calibration lives in a dedicated Flash page and isn't overwritten by firmware upgrades.

**Q: How do I enable NKRO?**
Toggle with Fn2 + Left Win (see Fn2 layer); or click **NKRO** under VIA **Functions › General**.
