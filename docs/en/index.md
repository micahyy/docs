# CZMao Documentation

## What is CZMao?

CZMao (czmao) is an open-source community focused on custom mechanical keyboards. We cover PCB design, firmware development, driver tools, and keyboard documentation. All PCB source files, firmware, and JSON files are hosted on GitHub and Gitee — free to download, not for commercial use.

## Get Started

### Manuals

[EC87 Electrostatic-Capacitive](/en/7_EC/EC87) — 87-key TKL electrostatic-capacitive keyboard with web-based actuation calibration. *(only product with full English manual)*

For manuals of other products, see the [Chinese documentation site](https://docs.micah.vip) (currently the canonical source for the rest of the lineup).
