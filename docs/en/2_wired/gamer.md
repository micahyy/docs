## 4. JSON file

The online private driver does not require a JSON file.

Driver URLs:

[micahyy.github.io](https://micahyy.github.io/) (overseas server)

[via.micah.vip](https://via.micah.vip/) (China server)

If you use the official VIA driver, download the JSON file and follow the [VIA usage guide](https://micahyy.github.io/docs/5.%E4%BD%BF%E7%94%A8%E6%95%99%E7%A8%8B/VIA%E4%BD%BF%E7%94%A8%E6%96%B9%E6%B3%95/).
