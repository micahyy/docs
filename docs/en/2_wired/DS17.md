## 1. Switches & indicators *("Mode switch" applies to multi-mode products only)*

- Port location: Type-C
- Indicators: NumberLock LED (white, solid while NumberLock is ON)
- Reset hole: printed on the PCB silkscreen / long-press to operate (follow the silkscreen)
- Mode switch: *N/A (single-mode, wired only)*

## 2. Shortcuts / combo keys

| Combo | QMK keycode | Description | Notes |
| :-- | :-- | :-- | :-- |
| Long-press NumberLock | LT(1, KC_NUM) | Short press: toggle NumberLock; long press: enter FN layer for combos | Indicator stays solid white while NumberLock is ON |
| FN + `7` | RGB_TOG | Turn per-switch RGB on / off | Hold NumberLock, then press `7` |
| FN + `0` | RGB_MOD | Cycle RGB modes | Hold NumberLock, then press `0` |
| FN + `8` | RGB_SAI | Saturation + | Hold NumberLock, then press `8` |
| FN + `2` | RGB_SAD | Saturation − | Hold NumberLock, then press `2` |
| FN + `4` | RGB_HUD | Hue + | Hold NumberLock, then press `4` |
| FN + `6` | RGB_HUI | Hue − | Hold NumberLock, then press `6` |
| FN + `-` | RGB_VAI | Brightness + | Hold NumberLock, then press `-` |
| FN + `+` | RGB_VAD | Brightness − | Hold NumberLock, then press `+` |
| FN + `*` + `-` | NK_TOGG | Toggle NKRO / 6-KRO | Hold NumberLock, then press `*` and `-` in sequence |
| Stand-alone function | QK_CLEAR_EEPROM | Set ENTER on layer 7 to factory-reset the board | |

## 3. Lighting

- Default effect: per-switch RGB is ON by default (animation needs the shortcuts in §2 or the tool below)
- Customization tool:
  - Web driver (recommended, no JSON needed): [micahyy.github.io](https://micahyy.github.io/) (overseas) / [via.micah.vip](https://via.micah.vip/) (China)
  - Official VIA: [JSON download](https://pan.baidu.com/s/10NhRV1l4iwE4XgSD4_ZZdQ?pwd=ufxm) (a17a18_ds17r3_via.json) + [VIA guide](https://micahyy.github.io/docs/5.%E4%BD%BF%E7%94%A8%E6%95%99%E7%A8%8B/VIA%E4%BD%BF%E7%94%A8%E6%96%B9%E6%B3%95/)
  - Note: the JSON version may differ from the PCB revision, but it still pairs and works correctly.

## 4. Firmware upgrade *(flashable products only)*

**Tools:** QMK Toolbox

**R3 firmware:** no bootloader included — flash it with QMK Toolbox.
- [Baidu Pan czmao_ds17_v3_3_via.bin](https://pan.baidu.com/s/1dMgO4e6GqgeQdm2vjf93QA?pwd=38r4)

**R4 firmware:** removes the diodes used in R3 and uses a direct-pin matrix (each pin triggers on GND). Performance is identical to R3.
- Same link as R3 (the same .bin).

**Rollback:** re-flash the same firmware version.

## 5. Cautions

- Cable: neither the kit nor the PCB includes a Type-C data cable — bring your own.
- Numpad layout: keys are mapped to the numpad region; **Number Lock must be ON** for number input.
- Arrow-key conflict: when Number Lock is OFF, keys 8 / 4 / 2 / 6 act as Up / Left / Down / Right.
- Num-Lock state: the board reads the host's current state; you can also toggle it from another keyboard.
- Soldering: 0402 components require SMT capability — consider outsourced SMT assembly if not.

## 6. Troubleshooting

| Symptom | Cause | Fix |
| :-- | :-- | :-- |
| Board suddenly stops working (number keys don't respond) | Num-Lock is OFF, keys remapped to arrows | Turn on Num-Lock: long-press the NumberLock key on this board, or toggle from another keyboard. |
