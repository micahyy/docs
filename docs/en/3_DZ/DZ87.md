# DZ87

87-key dual-mode mechanical keyboard · USB wired + Bluetooth 5.0 · ZMK firmware

> The DZ87 is an 87-key (TKL layout) dual-mode keyboard from CZMao: powered by an nRF52840, it supports both USB wired and Bluetooth 5.0, features 6 monochrome status LEDs, runs ZMK firmware and supports live keymap editing via ZMK Studio. The physical layout supports ANSI/ISO variants (split backspace, split space, multiple Shift/Enter widths) — all variant positions are visible in ZMK Studio.

## 2. LED indicators

### 2.1 Channel & status LEDs

| LED | Color | Meaning |
| :--: | :--: | :-- |
| CapsLock | White | Follows the host Caps Lock state: solid on when active, off otherwise |
| ScrollLock | White | Follows the host Scroll Lock state: solid on when active, off otherwise |
| BLE 1 | White | Bluetooth profile 1 |
| BLE 2 | White | Bluetooth profile 2 |
| BLE 3 | White | Bluetooth profile 3 |
| USB | White | USB wired channel |

> All six indicator LEDs are white; the channel is told apart by position.

**LED behavior (channel LEDs are status-only: they confirm a state and then turn off to save power):**

- In Bluetooth mode, the channel LED **blinks (~1 Hz) while advertising / not connected for ~30 seconds**, then turns off; switching profile or reconnecting restarts the blink.
- Once connected, the channel LED stays **solid for 3 seconds** as confirmation, then turns off; it resumes the 30-second blink if the connection is lost.
- When the USB channel is selected, the USB LED stays **solid for 3 seconds** as confirmation, then turns off; all BLE channel LEDs remain off.
- **Plugging in the USB cable always forces the keyboard back to USB mode**, regardless of the current state.
- The CapsLock and ScrollLock LEDs are independent and follow the host state.

## 3. Shortcuts

The keyboard has two function layers:

- **FN layer**: hold the **FN** key (bottom row, left of Right Ctrl) for BLE profiles, media keys and other frequently used functions.
- **FN2 layer**: hold **FN** and press **Right Alt** (there is no separate FN2 key on the standard layout). Used for Studio unlock, clearing pairings, bootloader and other maintenance functions.

### 3.1 FN layer (hold FN, then tap)

| Combo | Function |
| :-- | :-- |
| FN + `1` | Switch to BLE profile 1 (hold 1s to enter pairing mode) |
| FN + `2` | Switch to BLE profile 2 (hold 1s to pair) |
| FN + `3` | Switch to BLE profile 3 (hold 1s to pair) |
| FN + `4` | Manually select USB wired output (usually automatic when the cable is plugged in) |
| FN + `P` | Launch the system media player |
| FN + `C` | Launch the system calculator |
| FN + `Space` | Play / pause |
| FN + `↑` | Volume up |
| FN + `↓` | Volume down |
| FN + `←` | Previous track |
| FN + `→` | Next track |
| FN + `Right Alt` | Enter the FN2 maintenance layer |

> To use a combo: hold **FN** down, tap the target key, then release.

### 3.2 FN2 layer (hold FN, tap Right Alt, then tap)

| Combo | Function |
| :-- | :-- |
| FN + Right Alt + `` ` `` (the `~` key right of ESC) | Unlock ZMK Studio (live remap) |
| FN + Right Alt + `ESC` | Clear all Bluetooth pairings |
| FN + Right Alt + `Left Ctrl` | Enter bootloader (UF2 flashing mode) |

## 4. Bluetooth pairing

1. Hold FN and press `1` / `2` / `3` to select a BLE profile.
2. The channel LED **blinks for ~30 seconds** while advertising (hold FN + the number for 1s to restart it). Find `czm_dz_87_ble_x` in your device's Bluetooth list and pair.
3. The channel LED stays **solid for 3 seconds**, then turns off.
4. Each profile pairs with one device (up to 3). Use FN + `1/2/3` to switch.
5. If pairing fails or you change host, use FN + Right Alt + `ESC` to clear pairings, then pair again.
6. With the USB cable plugged in the keyboard forces USB mode; unplug or press FN + `4` to return to Bluetooth.

## 5. Remapping

DZ87 runs ZMK. We recommend **ZMK Studio** for live keymap editing:

1. Connect the keyboard via USB (Studio is not available over Bluetooth).
2. Once the keyboard is detected, hold FN, tap Right Alt to enter the maintenance layer, then press `` ` `` to unlock; drag-and-drop keys live.
3. Three layout views are available in Studio (layout switch menu in the top-right corner):

   - **ANSI 6.25u space (default)**: Standard ANSI 87-key layout (factory default).
   - **ANSI 7u space**: ANSI layout with a 7u spacebar (no Right Win key).
   - **All positions (ALL)**: Shows all 94 switch positions on the PCB — ISO enter / NUBS, split backspace, split space and all other variants. Switch to this view if your board has non-standard switches soldered in.

   Switching views never loses your keymap: functionally equivalent positions (split space switches, split backspace) are migrated automatically; positions that don't exist on your board are simply left untouched.
4. The keyboard re-locks automatically when USB is disconnected.

Advanced users can edit the open-source config repo and build firmware themselves:
[github.com/micahyy/zmk-config](https://github.com/micahyy/zmk-config) (shield name: `dz_87`)

## 6. Flashing firmware

1. Hold FN, tap Right Alt to enter the maintenance layer, then press `Left Ctrl` to enter the bootloader (or double-tap the RESET button on the module).
2. A USB mass-storage drive named `NICENANO` will appear.
3. Drag the `.uf2` firmware file onto the drive; the keyboard reboots and flashes automatically.

Get the firmware from the **Firmware download** section at the bottom of this page.

## 7. Power & sleep

- Built-in rechargeable Li-ion battery, charged via Type-C.
- After ~5 minutes of inactivity the keyboard enters light sleep (Bluetooth stays connected, wakes instantly); after ~15 minutes it enters deep sleep (Bluetooth off, all LEDs off) — press any key to wake and reconnect.
- If a power switch is fitted, turn it off for long-term storage.

# Power consumption and battery notes

## Measured power consumption

Measured on the current hardware configuration (nRF52840 module + ZMK firmware, no RGB, no display, single-colour indicator LEDs only).

| State | Average current | Notes |
| :--- | :--- | :--- |
| **Idle (no input)** | **~23 µA** | Bluetooth stays connected; the keyboard sits in an ultra-low-power sleep state |
| **Intermittent typing** | **~350–500 µA** | Average draw at a normal typing pace |
| **Continuous fast typing** | **~800 µA** | Average draw during sustained heavy input |
| **First 17 seconds after power-on** | **~144 µA** | Average current during init, advertising and connection setup |
| **Peak current** | **~6–9 mA** | Momentary peak when transmitting BLE packets; extremely short |

> Measured with a power profiler at 4.2 V (fully charged Li-ion). Actual figures vary slightly with battery voltage, ambient temperature and other factors.

## Battery life estimate

Based on a **2500 mAh** Li-ion battery:

| Usage | Daily drain | Estimated battery life |
| :--- | :--- | :--- |
| 10 h typing + 14 h idle per day | ~8.33 mAh/day | **about 10 months** |
| 2 h typing + 22 h idle per day | ~2.11 mAh/day | **about 1.3 years** |
| Idle only (no typing) | ~0.56 mAh/day | Extremely long in theory; in practice limited by battery self-discharge |

> These estimates assume deep sleep is disabled and Bluetooth stays connected (instant-on). Real-world battery life is slightly shorter due to self-discharge, aging and usage habits.

## Battery health

Power draw is extremely low, so the battery stays in the healthy **30%–70%** range most of the time, naturally avoiding the two main aging factors: long-term float charging at full and deep discharge.

- Charging is rare (about once every 10 months), so cycle life is hardly a bottleneck.
- No reliance on deep sleep — Bluetooth stays connected, avoiding the experience loss of frequent reconnects.
- Under normal use the battery will not swell or show other abnormal behaviour for years.

## Power design notes

- Uses the nRF52840's internal DC/DC converter; the battery goes straight to VDDH with no external LDO, giving high conversion efficiency and low quiescent current.
- An SS14 Schottky diode in the charging path drops about 0.25–0.35 V between the charger IC output and the battery, keeping the charge cut-off voltage in the healthy range.
- No RGB, no display or other extra loads, minimising static leakage at the source.

## Power source compatibility

| Power source | Voltage | Connection | Supported |
| :--- | :--- | :--- | :--- |
| Li-ion battery (single cell) | 3.0–4.2 V | VDDH (via SS14) | ✅ Yes |
| USB 5 V | 5 V | VDDH (via SS14) | ✅ Yes |
| Dry cells (2 in series) | 3.0 V | VDDH | ❌ No (below the 3.3 V minimum for VDDH) |
| Dry cells (2 in series) | 3.0 V | VDD (requires rewiring) | ✅ Yes (Normal Voltage Mode) |

> To run on dry cells, connect the battery positive to the VDD net instead of the VDDH path.

## 8. FAQ

**Q: The channel LED keeps blinking and won't connect?**
A: Make sure Bluetooth is enabled on the host. If it still fails, press FN + Right Alt + `ESC` to clear pairings, remove the old entry from the host, then pair again.

**Q: Connected via USB but no input?**
A: Plugging in the cable normally selects USB (the USB LED lights for 3s). If something seems off, press FN + `4` to toggle the output manually.

**Q: The CapsLock / ScrollLock LED doesn't light up?**
A: These LEDs follow the host's lock states — make sure Caps Lock / Scroll Lock is turned on.

**Q: The remap page can't detect or unlock the keyboard?**
A: ZMK Studio only works over USB. Plug in the cable, refresh the page, then hold FN, tap Right Alt and press `` ` `` to unlock.

**Q: My switches (ISO enter / split space) don't appear in the Studio layout?**
A: Switch the layout view to **All positions (ALL)** (layout menu in Studio's top-right corner) — it shows all 94 switch positions. Standard ANSI boards can stay on the default **ANSI 6.25u** view.
