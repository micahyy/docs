# 下载中心

固件、VIA 键位定义、图纸与文档汇总，共 **64** 个文件，合计 **8.7 MB**。按左侧菜单的分类划分，大类下再按型号分组。

## 下载前请读

1. **固件**（`.uf2`）：按住键盘左上角 `Esc` 再插 USB 线进入刷机模式，电脑上出现名为 `UF2BOOT` 的 U 盘，把文件拖进去即可。
2. **键位定义**（`.json`）：只有在 [菜籽猫版 VIA](https://via.micah.vip) 里找不到对应型号时才需要手动导入。
3. **刷固件不会清除校准数据**，静电容键盘刷完无需重做触底校准。
4. **图纸**（`.dxf`）需配合对应结构件使用，下单加工前请先确认版本。
5. 文件名含型号信息（如 `a14_ds17_R2_via.json` 对应 DS17），找不到请先确认键盘版本。
6. 缺少文件或链接失效，请在 QQ 群 **677654482** 反馈。
