# DZ17

17 键双模数字小键盘 · USB 有线 + 蓝牙 5.0 · ZMK 固件

677654482
::::

**卖点**

- **双模连接**：USB 有线 + 蓝牙 5.0（nRF52840），3 个蓝牙通道 + USB 共可配对 4 台设备，FN 一键切换，多设备党友好
- **实时改键**：ZMK Studio 网页拖改键位，即改即生效，不用编译、不用刷固件
- **开源固件**：ZMK 社区生态，[配置仓库](https://github.com/micahyy/zmk-config)完全公开，可自行深度定制
- **无感切换**：插上 USB 线自动切有线，拔掉自动回蓝牙；功耗低到只需浅睡眠——蓝牙常连即按即用，无需唤醒、不吞键

**设计理念**

> DZ17 是 DS17 的无线版本：主控为 nRF52840，支持 USB 有线和蓝牙 5.0 双模，板载 5 颗单色状态指示灯，使用 ZMK 固件，支持 ZMK Studio 实时改键。
>
> 整把键盘围绕一个词设计——**纯粹低功耗**：没有 RGB、没有屏幕、没有任何额外负载，指示灯也只做"提示"不做"氛围"，通道灯在确认状态后自动熄灭。电源上采用 nRF52840 内部 DC/DC 转换器、电池直入 VDDH、无外部 LDO，从源头压低静态漏电。实测**待机电流仅 ~20 µA**（蓝牙保持常连，即按即用），**工作时平均 ~700 µA**。固件选 ZMK 而非私有方案，键盘不依赖厂商存活：任何时候你都能自己改键、自己编译、自己修。

## 2. 指示灯说明

### 2.1 通道与状态灯

| 灯 | 颜色 | 位置 | 含义 |
| :--: | :--: | :--: | :-- |
| NumLock | 白 | `NUM` 键下方 | 跟随电脑数字锁定状态：NumLock 开启时常亮，关闭时熄灭 |
| BLE 1 | 白 | `1` 键下方 | 蓝牙通道 1 指示灯 |
| BLE 2 | 白 | `2` 键下方 | 蓝牙通道 2 指示灯 |
| BLE 3 | 白 | `3` 键下方 | 蓝牙通道 3 指示灯 |
| USB | 白 | `4` 键下方 | USB 有线通道指示灯 |
| 充电 | 白 | `7` 键下方 | 充电状态指示灯（见 2.2 节） |

> 5 颗通道/状态灯均为白色 LED，位置即身份：BLE 1/2/3 与 USB 灯正好位于对应 FN 切换键（FN + `1`/`2`/`3`/`4`）下方，选哪个通道看哪个位置的灯即可。

**灯效逻辑**（通道灯为提示型，确认后熄灭以省电）：

| 状态 | 对应指示灯 | 表现 |
| :-- | :-- | :-- |
| 蓝牙未连接 / 正在广播配对 | 对应通道灯 | **闪烁**（约每秒一次），30 秒后自动熄灭；切换通道、断开重连会重新开始闪烁 |
| 蓝牙连接成功 | 对应通道灯 | **常亮 3 秒**后自动熄灭；使用中断开连接则恢复 30 秒闪烁 |
| 切换到 USB 有线通道 | USB 灯 | **常亮 3 秒**后自动熄灭，三个通道灯保持熄灭（蓝牙与 USB 互斥） |
| 插入 USB 线（任何状态下） | USB 灯 | **强制切回 USB 有线模式**，USB 灯常亮 3 秒后熄灭 |
| NumLock 开 / 关 | NumLock 灯 | 不适用以上规则：跟随电脑状态常亮 / 熄灭 |

### 2.2 充电指示灯

充电灯由硬件（TP4056）直接控制，与固件无关（仅自行加装锂电池后适用）：

- ⚪ 充电灯：充电中常亮
- 充满电后熄灭

### 3.2 FN 功能层（长按 NUM 不放，再按对应键）

| 快捷键 | 功能 |
| :-- | :-- |
| FN + `1` | 切换到蓝牙通道 1 |
| FN + `2` | 切换到蓝牙通道 2 |
| FN + `3` | 切换到蓝牙通道 3 |
| FN + `4` | 切换 USB / 蓝牙输出通道 |
| FN + `*` | ZMK Studio 解锁（实时改键） |
| FN + `-` | 进入 Bootloader（UF2 烧录模式） |
| FN + `.` | 清除蓝牙配对信息 |

> 组合键操作方式：先按住 `NUM` 键不放，再按下对应的数字/符号键，然后松开。

## 4. 蓝牙配对与使用

1. 长按 `NUM` 进入 FN 层，按 `1` / `2` / `3` 选择一个蓝牙通道
2. 对应通道灯开始**闪烁**（约 30 秒后熄灭，重新按通道键可再次广播），在电脑/手机的蓝牙列表中搜索 `czm_dz17_ble_x`（x 为通道号）并连接
3. 连接成功后通道灯**常亮 3 秒**后熄灭，表示连接成功
4. 3 个通道可分别配对 3 台设备，FN + `1/2/3` 一键切换
5. 切换电脑或连不上时，用 FN + `.` 清除当前通道配对后重新配对
6. 插着 USB 线时，可用 FN + `4` 在 USB 有线和蓝牙之间切换

## 5. 改键

DZ17 使用 ZMK 固件，推荐通过 **ZMK Studio** 实时改键：

1. 打开[菜籽猫驱动中心](https://key.micah.vip)（国内服务器）
2. 用 USB 线连接键盘（蓝牙模式下不支持 Studio）
3. 网页识别到键盘后，按 FN + `*` 解锁，即可在网页上实时拖改按键
4. 拔掉 USB 后自动重新锁定

高级用户也可以直接修改开源配置仓库自行编译固件：
[github.com/micahyy/zmk-config](https://github.com/micahyy/zmk-config)（shield 名：`dz17`）

## 6. 固件烧录

1. 长按 `NUM`，按 `-` 进入 Bootloader；或双击主控模块上的复位键
2. 电脑上会出现一个名为 `NICENANO` 的 U 盘
3. 将 `.uf2` 固件文件拖入该 U 盘，键盘会自动重启并完成烧录

固件文件见文末[「固件下载」](#📥-固件下载)区块。

## 7. 电源与睡眠

- 键盘销售不含电池，Type-C 直接供电；外壳最大可内置 2500 mAh 锂电池，加装后充电状态见[2.2 节](#_22-充电指示灯)。按 20 µA 待机 / 700 µA 工作计算，2500 mAh 电池充满后可待机以年计
- 功耗极低（待机 ~20 µA），因此**只保留浅睡眠、没有深度睡眠**：蓝牙始终保持连接，即按即用，无需唤醒等待、不会吞键
- 长时间不用建议关闭电源开关（如配备）

## 8. 常见问题

**Q：通道灯一直闪、连不上设备？**
先确认电脑蓝牙已打开；仍不行就 FN + `.` 清除配对，删掉电脑里的旧配对记录后重新配对。

**Q：插着 USB 线但打不了字？**
可能当前输出通道是蓝牙。按 FN + `4` 切换到 USB 通道，USB 灯亮 3 秒即 USB 模式。

**Q：NumLock 灯不亮？**
NumLock 灯跟随电脑 NumLock 状态。请确认电脑端数字锁定（NumLock）已开启；部分笔记本默认关闭小键盘 NumLock。

**Q：改键网页识别不到键盘？**
ZMK Studio 只在 USB 有线连接下工作，请插线后刷新页面，并按 FN + `*` 解锁。
