# DZ87

87 键双模机械键盘 · USB 有线 + 蓝牙 5.0 · ZMK 固件

> DZ87 是菜籽猫 87 键（TKL 配列）双模键盘：主控为 nRF52840，支持 USB 有线和蓝牙 5.0，板载 6 个单色指示灯位（CapsLock、ScrollLock、蓝牙通道 1 三颗实际可用，见 2.2 节），使用 ZMK 固件，支持 ZMK Studio 实时改键。配列兼容 ANSI/ISO 变体（分裂退格、分裂空格、多种 Shift/回车宽度），可在 ZMK Studio 中查看所有变体位置。

## 2. 指示灯说明

### 2.1 通道与状态灯

| 灯 | 颜色 | 含义 |
| :--: | :--: | :-- |
| CapsLock | 白 | 跟随电脑大写锁定状态：CapsLock 开启时常亮，关闭时熄灭 |
| ScrollLock | 白 | 跟随电脑滚动锁定状态：ScrollLock 开启时常亮，关闭时熄灭 |
| BLE 1 | 白 | 蓝牙通道 1 指示灯 |
| BLE 2 | 白 | 蓝牙通道 2 指示灯 |
| BLE 3 | 白 | 蓝牙通道 3 指示灯 |
| USB | 白 | USB 有线通道指示灯 |

> 6 个灯位均为白色 LED。**本批次 PCB 上只有 CapsLock、ScrollLock、BLE 1 三颗实际连接了 LED；BLE 2 / BLE 3 / USB 三个灯位不会亮**，详见 2.2 节。

**灯效逻辑**（通道灯为提示型，确认后熄灭以省电）：

> **注意**：以下灯效仅对 **BLE 1** 灯位有效（唯一实际可用的通道灯）。切换到蓝牙通道 2 / 3 或插入 USB 线时**没有任何指示灯提示**，但功能本身正常，详见 2.2 节。

- 蓝牙模式下，当前通道**未连接/正在广播配对** → 对应通道灯**闪烁**（约每秒一次），闪烁 **30 秒**后自动熄灭；切换通道、断开重连会重新开始闪烁
- 蓝牙**连接成功** → 对应通道灯**常亮 3 秒**后自动熄灭；使用中断开连接则恢复 30 秒闪烁
- 切换到 USB 有线通道时，USB 灯**常亮 3 秒**后自动熄灭，三个通道灯保持熄灭（蓝牙与 USB 互斥）
- **插入 USB 线即强制切回 USB 有线模式**（任何状态下）
- CapsLock / ScrollLock 灯不适用此规则，跟随电脑状态常亮/熄灭

### 2.2 已知硬件问题：LED 灯位设计失误

::: warning
**本批次 PCB 存在设计失误：蓝牙通道 2、蓝牙通道 3、USB 三个指示灯位没有实际连接 LED，永远不会亮。**

CapsLock、ScrollLock、蓝牙通道 1 三个灯位不受影响，正常工作。
:::

**实际表现**

| 操作 | 有没有指示灯提示 |
| :-- | :-- |
| 切到蓝牙通道 1 | 有：未连接时闪烁、连接成功常亮 3 秒 |
| 切到蓝牙通道 2 / 3 | 无（该灯位没有 LED） |
| 插入 USB 线 | 无（该灯位没有 LED） |
| CapsLock / ScrollLock | 正常，跟随电脑锁定状态 |

**不影响的部分**：蓝牙配对、通道切换、USB 有线输出、按键输入**全部正常**，仅仅是缺少灯光提示，不是故障。

**没有指示灯时怎么确认当前通道**

- 看哪台主机在接收按键——只有当前通道会输出
- 在主机蓝牙设置里看已连接设备名：`czm_dz_87_ble_1` / `czm_dz_87_ble_2` / `czm_dz_87_ble_3`
- 插入 USB 线即强制切回 USB 有线输出，不需要指示灯确认

## 3. 快捷键

键盘有两个功能层：

- **FN 层**：长按主键区右下角的 **FN** 键（右 Ctrl 左侧）进入，用于蓝牙通道、多媒体等常用功能
- **FN2 层**：按住 **FN** 再按 **右Alt** 组合进入（标准 87 键配列无独立 FN2 键）。用于 Studio 解锁、清配对、Bootloader 等维护功能

### 3.1 FN 层（按住 FN，再按对应键）

| 快捷键 | 功能 |
| :-- | :-- |
| FN + `1` | 切换到蓝牙通道 1（长按 1 秒进入该通道配对模式） |
| FN + `2` | 切换到蓝牙通道 2（长按 1 秒进入配对模式） |
| FN + `3` | 切换到蓝牙通道 3（长按 1 秒进入配对模式） |
| FN + `4` | 手动切换到 USB 有线输出（插入 USB 线时通常自动切换） |
| FN + `P` | 打开系统默认媒体播放器 |
| FN + `C` | 打开系统计算器 |
| FN + `空格` | 播放 / 暂停 |
| FN + `↑` | 音量加 |
| FN + `↓` | 音量减 |
| FN + `←` | 上一曲 |
| FN + `→` | 下一曲 |
| FN + `右Alt` | 进入 FN2 维护层（再按维护键） |

> 组合键操作方式：先按住 **FN** 不放，再按下对应键，然后松开。

### 3.2 FN2 维护层（按住 FN 不放，按 右Alt 保持进入 FN2 层，再按对应键）

| 快捷键 | 功能 |
| :-- | :-- |
| FN + 右Alt + `` ` ``（ESC 右侧的 `~ 键） | ZMK Studio 解锁（实时改键） |
| FN + 右Alt + `ESC` | 清除蓝牙配对信息 |
| FN + 右Alt + `左Ctrl` | 进入 Bootloader（UF2 烧录模式） |

## 4. 蓝牙配对与使用

1. 按住 FN，按 `1` / `2` / `3` 选择一个蓝牙通道
2. 对应通道灯开始**闪烁**（约 30 秒后熄灭；长按 FN+对应数字键 1 秒可重新进入配对广播），在电脑/手机的蓝牙列表中搜索 `czm_dz_87_ble_x`（x 为通道号）并连接。**注意：只有通道 1 的灯会闪，通道 2 / 3 没有任何灯光提示**（见 2.2 节），请直接在蓝牙列表里按设备名寻找
3. 连接成功后通道灯**常亮 3 秒**后熄灭，表示连接成功（仅通道 1 有此提示；通道 2 / 3 无灯，直接试打字确认即可）
4. 3 个通道可分别配对 3 台设备，FN + `1/2/3` 一键切换
5. 切换电脑或连不上时，用 FN + 右Alt + `ESC` 清除配对后重新配对
6. 插着 USB 线时强制走 USB 有线：FN + `1/2/3` 只切换蓝牙通道，**不会把输出从 USB 抢走**；FN + `4` 也只能切到 USB。拔掉 USB 线后自动回到蓝牙工作

> **关于多台设备同时显示「已连接」（ZMK 既定行为，并非故障）**
> 3 个蓝牙通道共用同一个蓝牙 MAC 地址，切换通道时原先那台设备**不会主动断开**，因此可能出现两台甚至三台设备同时显示「已连接」。这是 ZMK 官方明确说明的既定行为（官方原文：*"A ZMK device may show as connected on multiple hosts at the same time. This is working as intended, and only the host associated with the active profile will receive keystrokes."*）——**只有当前选中的那个通道会收到按键**。
> 建议每台主机固定占用一个通道，不要在同一台电脑上配对多个通道。

## 5. 改键

DZ87 使用 ZMK 固件，推荐通过 **ZMK Studio** 实时改键：

1. 打开 [菜籽猫驱动中心](https://zmk.micah.vip)（官方版：[zmk.studio](https://zmk.studio)）
2. 用 USB 线连接键盘（蓝牙模式下不支持 Studio）
3. 网页识别到键盘后，按住 FN 按 右Alt 进入维护层，再按 `` ` `` 键解锁，即可在网页上实时拖改按键
4. Studio 中有三种配列视图可选（键盘右上角配列切换菜单）：

   - **ANSI 6.25u 空格（默认）**：标准美式 87 键配列，出厂即此视图
   - **ANSI 7u 空格**：空格 7u、无右 Win 键的配列
   - **全轴通用 ALL**：显示 PCB 上全部 94 个轴位，包含 ISO 回车/NUBS、分裂退格、分裂空格等所有变体位置。焊接了非标准轴位（如 ISO 大回车、分裂空格）时切到这个视图即可对所有轴改键

   切换视图不会丢失已改的键：同一功能的位置（如分裂空格各轴、分裂退格）会自动迁移，实际不存在的轴位保持原样不受影响。
5. 拔掉 USB 后自动重新锁定

高级用户也可以直接修改开源配置仓库自行编译固件：
[github.com/micahyy/zmk-config](https://github.com/micahyy/zmk-config)（shield 名：`dz_87`）

## 6. 固件烧录

1. 按住 FN 按 右Alt 进入维护层，再按 `左Ctrl` 进入 Bootloader；或双击主控模块上的复位键
2. 电脑上会出现一个名为 `NICENANO` 的 U 盘
3. 将 `.uf2` 固件文件拖入该 U 盘，键盘会自动重启并完成烧录

固件文件见**文末「固件下载」**区块。

## 7. 电源与睡眠

- 键盘内置可充电锂电池，Type-C 充电
- 闲置约 5 分钟进入浅睡眠省电（蓝牙保持连接，任意键即时唤醒）；约 15 分钟进入深度睡眠（断开蓝牙，指示灯全灭），按任意键唤醒并自动重连
- 长时间不用建议关闭电源开关（如配备）

### 7.1 实测功耗数据

以下数据基于当前硬件配置（nRF52840 模块 + ZMK 固件，无 RGB、无屏幕，仅单色指示灯）实测得出。

| 工作状态 | 平均电流 | 说明 |
| :--- | :--- | :--- |
| **待机（无输入）** | **~23 µA** | 蓝牙保持连接，键盘处于极低功耗休眠状态 |
| **间歇打字** | **~350–500 µA** | 普通打字节奏下的平均功耗 |
| **持续快速打字** | **~800 µA** | 连续高强度输入时的平均功耗 |
| **上电初期（前 17 秒）** | **~144 µA** | 初始化、广播、连接建立阶段的平均电流 |
| **峰值电流** | **~6–9 mA** | 蓝牙发送数据包瞬间的峰值，持续时间极短 |

> 注：以上数据使用功耗测试仪实测，测试电压为 4.2V（锂电池满电状态）。实际功耗会随电池电压下降、使用环境温度等因素略有波动。

### 7.2 续航估算

以 **2500 mAh** 锂电池为例：

| 使用场景 | 日均耗电 | 理论续航 |
| :--- | :--- | :--- |
| 每天打字 10 小时 + 待机 14 小时 | ~8.33 mAh/天 | **约 10 个月** |
| 每天打字 2 小时 + 待机 22 小时 | ~2.11 mAh/天 | **约 1.3 年** |
| 纯待机（不打字） | ~0.56 mAh/天 | 理论值极长，实际受电池自放电限制 |

> 以上估算未开启深度睡眠，键盘保持蓝牙常连，即按即用。实际续航会因电池自放电、老化及使用习惯略有缩短。

### 7.3 电池健康说明

本键盘功耗极低，电池长期处于 **30%–70% 的健康电量区间**，自然避开了“长期满电浮充”和“深度放电”两大电池老化诱因。

- 充电频率极低（约 10 个月一次），电池循环寿命几乎不构成瓶颈。
- 不依赖深度睡眠，保持蓝牙常连，避免频繁重连带来的体验损失。
- 正常使用条件下，电池在数年内不会出现鼓包等异常问题。

### 7.4 电源设计说明

- 采用 nRF52840 内部 DC/DC 转换器，电池直接接入 VDDH，无需外部 LDO，转换效率高、静态功耗低。
- 充电回路串联 SS14 肖特基二极管，在充电 IC 输出与电池之间形成约 0.25–0.35V 压降，将电池充电截止电压控制在健康区间。
- 无 RGB、无屏幕等额外负载，从源头降低静态漏电。

### 7.5 供电兼容性说明

| 电源类型 | 电压范围 | 接入方式 | 是否支持 |
| :--- | :--- | :--- | :--- |
| 锂电池（单节） | 3.0–4.2V | VDDH（经 SS14） | ✅ 支持 |
| USB 5V | 5V | VDDH（经 SS14） | ✅ 支持 |
| 干电池（两节串联） | 3.0V | VDDH | ❌ 不支持（低于 VDDH 最低 3.3V 要求） |
| 干电池（两节串联） | 3.0V | VDD（需改走线） | ✅ 支持（Normal Voltage Mode） |

> 如需使用干电池供电，需将电池正极接入 VDD 网络，而非 VDDH 路径。

## 8. 常见问题

**Q：通道灯一直闪、连不上设备？**
A：先确认电脑蓝牙已打开；仍不行就 FN + 右Alt + `ESC` 清除配对，删掉电脑里的旧配对记录后重新配对。（注：只有通道 1 的灯位有 LED，通道 2 / 3 不会闪也不会亮，详见 2.2 节。）

**Q：切到通道 2 / 3，或插上 USB 线，指示灯完全不亮，是不是坏了？**
A：不是故障，是本批次 PCB 的设计失误：通道 2、通道 3、USB 三个灯位没有连接 LED。通道切换、蓝牙配对、USB 输出、按键输入**全部正常**，只是没有灯，详见 2.2 节。

**Q：插着 USB 线但打不了字？**
A：插入 USB 线会自动切到有线通道（**USB 灯位在本批次 PCB 上没有 LED，不会有任何灯光提示**，属正常现象，见 2.2 节）。万一输出偏到了蓝牙，按 FN + `4` 即可切回 USB —— FN + `4` **只选择 USB 有线输出**，不会切到蓝牙。若仍无反应，重新插拔一次 USB 线。

**Q：两台（或多台）设备都显示「已连接」，是不是坏了？**
A：不是故障。3 个蓝牙通道共用一个 MAC 地址，切换通道不会主动断开原先的设备，所以多台主机可能同时显示「已连接」，但**只有当前选中的通道能收到按键**。这是 ZMK 的既定行为，详见第 4 节的说明。建议每台主机固定占用一个通道。

**Q：CapsLock / ScrollLock 灯不亮？**
A：这两颗灯跟随电脑对应的锁定状态，请确认电脑端 Caps Lock / Scroll Lock 已开启。

**Q：改键网页识别不到键盘 / 提示未解锁？**
A：ZMK Studio 只在 USB 有线连接下工作，请插线后刷新页面，按住 FN 按 右Alt 进入维护层后按 `` ` `` 解锁。

**Q：Studio 配列图里看不到我键盘上的轴（ISO 回车 / 分裂空格等）？**
A：请把配列视图切换为「全轴通用 ALL」（Studio 右上角配列切换菜单），该视图显示 PCB 上全部 94 个轴位；标准 ANSI 键盘保持默认「ANSI 6.25u」视图即可。

## 9. 固件修复记录

::: warning
**2026-09-24 固件（czm_dz87_tri_260924）：修复「插着 USB 线时按 FN + `4`，之后所有按键都没有反应」**

- **现象**：键盘插着 USB 线正常打字时，按住 FN 按 `4`，此后**全部按键都无反应**；拔掉 USB 线改用蓝牙也依然打不出字。
- **原因**：出厂固件把 FN + `4` 绑定为「输出通道来回切换」（ZMK 的 `OUT_TOG`）。再次按下会把输出切到蓝牙，而键盘一旦检测到 USB 已连接就会主动断开蓝牙链路，输出于是被送到一个已经断开的通道上——USB 侧不接收、蓝牙侧也没连着，结果就是彻底没有输入。
- **修复**：新固件把 FN + `4` 改为「只选择 USB 有线输出」（`OUT_USB`）。插着线的状态下无论按多少次，都只会停在 USB 有线通道，不可能被切到蓝牙。想用蓝牙请先拔掉 USB 线，再用 FN + `1/2/3` 选择通道。
- **不刷固件的规避办法**：重新插拔一次 USB 线即可恢复有线输入；在此之前不要再按 FN + `4`。
- **影响固件**：2026-09-08（v9）及更早的出厂固件。2026-09-24 起发布的固件已修复，建议所有用户升级。
:::
