## 2. 开关与指示 *（仅多模产品含“模式切换”项）*

- 接线位置：Type-C
- 指示灯：NumberLock 灯（白色，NumberLock 打开时常亮）
- 复位孔：PCB 丝印位置 / 长按操作（具体以 PCB 丝印为准）
- 模式切换：*不适用（单模有线）*

## 3. 快捷键

| 快捷键 | 键值 | 说明 | 备注 |
| -------------- | --------------- | --------------------------------- | ---------------------------- |
| 长按 NumberLock | LT(1, KC_NUM) | 短按：切换 NumberLock 开关；长按：进入 FN 层使用组合键 | NumberLock 打开时指示灯常亮白色 |
| FN + `7` | RGB_TOG | 开启 / 关闭 RGB 轴灯 | 按住 NumberLock 再按 `7` |
| FN + `0` | RGB_MOD | 切换 RGB 灯效模式 | 按住 NumberLock 再按 `0` |
| FN + `8` | RGB_SAI | 增加饱和度 | 按住 NumberLock 再按 `8` |
| FN + `2` | RGB_SAD | 减少饱和度 | 按住 NumberLock 再按 `2` |
| FN + `4` | RGB_HUD | 增加色相（色度） | 按住 NumberLock 再按 `4` |
| FN + `6` | RGB_HUI | 减少色相（色度） | 按住 NumberLock 再按 `6` |
| FN + `-` | RGB_VAI | 增加亮度 | 按住 NumberLock 再按 `-` |
| FN + `+` | RGB_VAD | 减少亮度 | 按住 NumberLock 再按 `+` |
| FN + `*` + `-` | NK_TOGG | 全键无冲 / 6 键无冲切换 | 按住 NumberLock，再依次按 `*` 和 `-` |
| 独立功能 | QK_CLEAR_EEPROM | 在第 7 层的 ENTER 键设为：恢复出厂设置 | |

## 6. 注意事项

- 数据线：套餐及 PCB 不含 Type-C 数据线，需自备
- 小键盘区域：键值默认设为小键盘区域，**NumberLock 必须打开**才能输入数字
- 方向键冲突：NumberLock 关闭时，小键盘 8/4/2/6 变为 上/左/下/右 方向键
- NumberLock 状态：读取电脑当前状态，可用其他键盘切换
- DIY 焊接：0402 元件需贴片焊接能力，否则建议贴片代工

## 7. 故障排查

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 键盘突然不能用了（按数字键无反应） | NumberLock 关闭，按键被映射为方向键 | 打开电脑 NumberLock：长按本键盘 NumberLock 键，或用其他键盘切换 |
