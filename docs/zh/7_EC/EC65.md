# EC65

菜籽猫 68 键静电容键盘（65% ANSI 配列），QMK 固件，支持 VIA 在线改键与网页版触底校准。

## 2. 触底校准（自适应触发）

EC65 的静电容触发点会随胶碗、弹簧、温湿度和使用习惯产生轻微漂移。固件内置**自动学习**，无需任何手动操作：

- **正常打字就是在校准。** 每颗键在你按到底的过程中自动学习触底行程，按得越多次越贴合你的手感；
- 停止打字 5 秒后，学到的数据自动写入键盘内部 Flash；
- 数据**掉电不丢、刷新固件也不丢**（校准数据独立存放在芯片 Flash 的专用页，固件升级不会覆盖）；
- 未学习过的键使用出厂默认阈值，到手即可正常使用。

### 网页可视化校准（可选）

想一次性快速校准全部按键，或想可视化查看每颗键的学习状态：

1. 用 **Chrome / Edge** 浏览器打开 [**CZM 键盘触底校准**](https://tools.micah.vip/ectools)（通用校准页，本厂静电容 PCB 共用；也可从 micah.vip 顶部导航的 **EC tools** 进入）；
2. 插上键盘，点「**连接键盘**」，在弹出的设备列表里**选中你的键盘**（列表会列出本机所有 HID 设备，不限型号）；连上后确认左侧 PCB 型号高亮的是 **EC65**，不是就手动点一下；
3. 按你实际装的键帽，勾选顶部**配列选项**（空格长度、是否分裂空格 / 回车等），图上只显示当前勾选的配列；
4. 点击「**开始校准**」，键盘进入**静音模式**（此期间按键不向电脑输出，属正常现象），然后**把图上每个键按到底再松开**（正常力度按到底即可）；
5. 按压时键位显示**金色高亮**（已过滤空闲抖动，手不碰键盘不会有键闪烁），学会后**变绿打勾 ✓**；图上所有键全部变绿后点「**保存校准**」；
6. 中途想退出打字点「**恢复按键输出**」；点「**清空重来**」可清除已学数据、恢复出厂阈值；静音 10 分钟无操作也会自动恢复输出。

> 校准前请把键盘放稳、不要压住任何键。网页校准和自动学习共用同一套数据，混用不冲突；切换配列选项后新出现的键补按一遍即可。

## 3. 驱动与改键

- **在线改键**：打开菜籽猫版 VIA：**[via.micah.vip](https://via.micah.vip)**，点击 **Authorize device** 选择 EC65，即可可视化改键、改层、设置组合键，改完即时生效，无需刷机；
- 菜籽猫版 VIA 已内置本厂全部键盘的键位定义，连上就能识别，**无需手动导入 JSON**（官方 usevia.app 未收录本厂型号，不推荐使用）；
- 键盘共有两个功能层：**Fn**（底行，右 Alt 右侧、方向键 ← 左边）= Mo(1) 媒体与系统功能层；**Fn2** 通过 **Fn + 左 Alt** 组合进入（系统 / NKRO / 刷机功能层）。

### Fn 功能层（媒体 / 系统）

按住底行 **Fn**（右 Alt 右侧）：

| 快捷键 | 功能 | 备注 |
| :-- | :-- | :-- |
| Fn + P | 打开默认媒体播放器 |  |
| Fn + 空格 | 播放 / 暂停 |  |
| Fn + ← / → | 上一曲 / 下一曲 |  |
| Fn + ↑ / ↓ | 音量 + / 音量 - |  |
| Fn + Backspace | 静音 |  |
| Fn + Esc | `（反引号） |  |
| Fn + 1 … = | F1 … F12 | 依次对应 1 2 3 4 5 6 7 8 9 0 - = |
| Fn + 左 Alt | 进入 Fn2 层（Mo(2)） | 按住不松再按各 Fn2 键 |

### Fn2 功能层（Fn + 左 Alt）

**进入方式：按住底行 Fn 不松手，再按左 Alt**。按住此组合后再按下表按键：

| 快捷键 | 功能 |
| :-- | :-- |
| Fn2 + 左 Ctrl | 进入刷机模式（Bootloader） |
| Fn2 + Esc | 恢复出厂设置（恢复默认键位 ＋ 清除全部触底学习值 ＋ 自动复位） |
| Fn2 + 左 Win | 全键无冲（NKRO）开关 |

> Fn2 + Esc 与 VIA「功能 › 常规 › 恢复出厂设置」按钮是同一个动作：键位回到固件默认值、所有按键的触底学习值被清空、键盘自动复位一次。

### 进入刷机模式

以下两种方式任一即可（详见下节「固件升级」）：

1. 在 VIA 中执行 Bootloader 指令；
2. **Fn + 左 Alt + 左 Ctrl 三键同按**（Fn 为底行功能键）。

## 4. 固件升级

EC65 使用 uf2boot 引导，刷固件像拷文件一样简单：

1. 从菜籽猫提供的链接下载最新固件 `.uf2` 文件（**via 版**带完整改键功能，普通用户刷 via 版即可）；
2. 在 VIA 中执行 Bootloader 指令（或按 **Fn + 左 Alt + 左 Ctrl**），键盘会进入刷机模式，电脑上出现一个名为 **`UF2BOOT`** 的 U 盘；
3. 把 `.uf2` 文件**拖进这个 U 盘**，键盘会自动写入并重启，升级完成；
4. 刷错固件或键盘无反应时，重复第 2 步重新拖入正确固件即可，不会变砖。

> 固件升级不会清除触底校准数据。

## 5. 常见问题

**Q：需要手动校准吗？**
不需要。正常打字就会自动学习。网页校准只是给想"一次到位"或想看可视化数据的用户准备的。

**Q：VIA 网页识别不到键盘？**
① 确认用的是数据线不是纯充电线；② 换一个 USB 口重插；③ 浏览器必须是 Chrome 或 Edge（Safari / Firefox 不支持 WebHID）。

**Q：触发感觉变了 / 某颗键要按很重才触发？**
打开校准网页点「清空重来」，然后正常打字或重新走一遍网页校准即可；若仍异常，检查该键胶碗是否安装到位。

**Q：刷固件会丢校准数据吗？**
不会。校准数据存放在独立的 Flash 页，刷新固件不覆盖。

**Q：全键无冲怎么开？**
Fn2 + 左 Win 切换（见 Fn2 层说明）；也可在 VIA「功能 › 常规」里点「全键无冲（NKRO）」。
